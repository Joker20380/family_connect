# Приложения Family Connect 0.1

[English](clients.en.md) · [Главная](../README.ru.md)

## Что входит в этот выпуск

- Android: собственное приложение с встроенным официальным WireGuard GoBackend; отдельный
  WireGuard на телефоне не нужен. Android 8.0/API 26 и новее.
- Linux: настольный интерфейс на Python/Tk, управляющий WireGuard через NetworkManager.
- Windows: тот же интерфейс, управляющий сервисами установленного официального WireGuard.
  Требуются права администратора; сборка Windows выполняется на Windows в GitHub Actions.
- Импорт одного полного IPv4/IPv6-профиля, включение/выключение, фактическое системное состояние
  туннеля, ручная проверка внешнего IP и русский/английский интерфейс.

Это прямой WireGuard-клиент первого выпуска. Автоматические relay, семейные приглашения,
регистрация по ссылке, выбор gateway и собственный постоянный kill switch ещё не интегрированы.
Экспериментальный Rust-контур остаётся отдельным. Второй сервер для сайтов не используется.

## Android

Локальная сборка: `artifacts/clients/FamilyConnect-Android-debug.apk`.
В GitHub Actions: workflow **Client builds**, артефакт **FamilyConnect-Android-debug**.

1. Перенесите APK и личный `fc-ru-android.conf` на телефон по USB.
2. Установите APK; Android может запросить разрешение установки из этого источника.
3. Откройте Family Connect → «Добавить профиль устройства» → выберите `.conf`.
4. Нажмите «Подключить», разрешите VPN и, по желанию, уведомления.
5. Нажмите «Проверить внешний IP». Для текущего российского сервера ожидается `185.251.89.19`.

Отключите старое VPN-подключение перед использованием нового приложения. Это тот же личный
профиль устройства; не используйте одну конфигурацию одновременно на разных устройствах.
APK не содержит ваших ключей или готового VPN-профиля.

Профиль сохраняется в приватном хранилище приложения с AES-GCM; ключ шифрования создаётся
в Android Keystore. Файл исключён из резервного копирования и переноса устройства; экран
защищён FLAG_SECURE. Исходный импортированный файл приложение не удаляет: после импорта
его можно удалить самостоятельно. Кнопка удаления стирает сохранённый профиль и ключ хранилища.

При включении работает foreground service с уведомлением отключения. Закрытие Activity
не отключает VPN. Приложение не включает VPN при загрузке системы и не заявляет поддержку
Always-on: она явно отключена в манифесте до проверки жизненного цикла и восстановления.

Debug APK предназначен для закрытого тестирования. Для постоянных обновлений понадобится
отдельная release-подпись: debug-сборки с разных машин/CI могут иметь разные ключи подписи.
Это не выпуск Google Play. Работа на физическом телефоне, Wi-Fi/LTE и утечки требуют проверки.

## Linux

Нужны Python 3, Tk и NetworkManager с поддержкой WireGuard. На вашем ноутбуке эти компоненты
проверены, существующий `fc-ru-linux` обнаруживается автоматически.

```sh
./clients/desktop/install-linux.sh
```

После установки откройте **Family Connect** из меню приложений. Либо запустите:

```sh
python3 clients/desktop/app.py
```

Приложение показывает только свои профили `fc-app-*` и ранее созданный `fc-ru-linux`.
Импорт создаёт отдельный профиль в NetworkManager, отключает его автоподключение и задаёт
приоритет DNS полного туннеля. Временная копия конфигурации имеет права 0600 и удаляется;
постоянное хранение ключей и авторизация изменений передаются NetworkManager/Polkit.
Обычный пользователь запускает интерфейс без sudo. При необходимости ОС запросит разрешение.
Закрытие окна не отключает системный туннель; при известном активном состоянии показывается подтверждение.

## Windows

1. Установите [официальный WireGuard](https://www.wireguard.com/install/).
2. В GitHub → **Actions → Client builds** скачайте артефакт **FamilyConnect-Windows**.
3. Распакуйте **всю** папку, включая `_internal`; запустите `FamilyConnect.exe` и разрешите UAC.
4. Добавьте отдельный профиль Windows и нажмите Connect. Не используйте одновременно ключ
   работающего Linux/Android-устройства; отдельное устройство требует отдельного peer на gateway.

Приложение проверяет Authenticode-подпись установленного WireGuard. Профиль передаётся его
официальному manager service, который применяет ACL и преобразует файл в DPAPI-хранилище.
Family Connect не создаёт собственного постоянного plaintext-хранилища. Имена профилей
ограничены `fc-app-*`; сервисы других VPN не удаляются. Сервис приложения переводится в ручной
запуск; отключение удаляет только сервис выбранного профиля. Проверка IP выполняется по кнопке.

Windows-исполняемый файл создаётся PyInstaller на Windows; он не подписан Authenticode.
Системные предупреждения о неизвестном издателе не означают наличие подписи оператора.
Фактическая работа VPN и DPAPI на Windows пока не проверена на пользовательской машине.

## Проверки и сборка

Парсеры отклоняют скриптовые PostUp/PreUp и другие неизвестные поля, несколько peers,
повторяющиеся поля, неверные ключи, неполные маршруты IPv4/IPv6 и слишком большие профили.
Android дополнительно разбирает профиль официальной библиотекой. MVP принимает числовой
endpoint и DNS-адреса. Приватные ключи, конфигурации и содержимое трафика не выводятся в журнал приложения.

```sh
python3 -m pytest clients/desktop/tests -q
python3 clients/desktop/app.py --smoke

# Android: JDK 17, Gradle 8.11.1, SDK 35 / Build Tools 35.0.0
cd clients/android
gradle --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug

# Windows PowerShell, Python 3.12+
./clients/desktop/build-windows.ps1
```

Наличие активного интерфейса само по себе не доказывает рабочий интернет, поэтому интерфейс
показывает «Туннель включён», а проверка IP выполняется отдельно через Cloudflare.

Основания интеграции: [WireGuard embedding](https://www.wireguard.com/embedding/),
[сервисы и защищённое хранилище Windows](https://git.zx2c4.com/wireguard-windows/about/docs/enterprise.md).

Локальный ключ debug-подписи сохраняется только на ноутбуке в `state-client-build/android-signing/`, вне Git. Не удаляйте его, если нужны обновления поверх установленной локальной сборки.

### Диагностика Windows

Если список профилей пуст и настройка завершилась ошибкой, установите официальный WireGuard через кнопку «Установить WireGuard», затем нажмите «Повторить проверку». Family Connect должен работать от имени администратора. Проверка подписи WireGuard остаётся обязательной. После успешной проверки добавьте отдельный профиль Windows через «Добавить профиль». Клиент показывает конкретную причину ошибки настройки; содержимое профиля и вывод системных команд не выводятся.
