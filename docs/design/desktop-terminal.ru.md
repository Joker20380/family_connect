# Единый интерфейс Family Connect

Эталон — установленный Android 0.1.18-beta19. Desktop использует тот же логотип,
спокойную терминальную графику и названия разделов. Адаптация размеров под окно
не должна менять смысл элементов или прятать нижнюю навигацию.

| Элемент | Значение |
| --- | --- |
| Фон | `#03110e` |
| Карточка | `#072018` |
| Контур | `#438e79` |
| Основной текст | `#dafff2` |
| Вторичный текст | `#99c4b5` |
| Включено | `#98f7d8` |
| Выключено / выбранная вкладка | `#ffad46` |

Шапка: знак из Android `ic_brand.xml`, FAMILY CONNECT, SECURE NETWORK TERMINAL,
две короткие слабые линии возле подзаголовка и три оранжевых штриха слева.
Карточки и кнопки имеют срезанные углы. Переключатель — короткая капсула:
положение и цвет одновременно обозначают состояние; подпись сохраняется.
Системные заголовки окон, разрешения и выбор файлов остаются платформенными.

Постоянные вкладки: **Статус, Мессенджер, Маршрут, Настройки**.
Версия, язык, импорт/активация и обновление располагаются в настройках.
Маршрут содержит текущие доступные действия выбора подключения; интерактивная
карта Android ещё не перенесена. Desktop-мессенджер пока явно обозначен как
разрабатываемый: пустая вкладка не считается реализованной перепиской.

Linux рисует рамки и логотип в GTK snapshot из SVG в коде app.py, сохраняя
шесть файлов standalone-архива. Windows использует WinForms/GDI+ и native
Button для клавиатуры и accessibility. Проверять обе локали, масштаб 100–250%,
малое окно и сохранение вкладок на каждом экране. Windows cross-build
не заменяет Windows CI и проверку на настоящем компьютере.
