# Family Connect Test — короткая инструкция

Актуальная инструкция: [установка, активация и обновление](../getting-started.ru.md).
Страница приглашения и обновления предлагают beta50; активация выполняется открытием приложения по исходной ссылке.

После обновления выберите страну/транспорт на главной, включите VPN и подтвердите
системный запрос. В «Маршруте» проверьте внешний IP; геолокация карты необязательна.
Текст отправляется стрелкой, голосовое — удержанием микрофона; свайп вверх фиксирует,
влево отменяет. При новом сообщении чат прокручивается к нему автоматически.
