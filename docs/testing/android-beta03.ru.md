# Android beta03: проверка связи и устойчивость

Новая версия0.1.2-beta03/code3 использует тот же AWG3.1 движок и профиль Амстердама,
что beta02. Платформенная приёмка, ARM64-упаковка и подпись завершены; файл готов к установке.
Телефон в России сейчас недоступен владельцу; физические проверки отложены.

## Что изменено

Под названием состояния туннеля показана проверка связи:

- «Проверка связи через VPN…» — первая проверка ещё выполняется.
- «VPN отвечает» — DNS-запрос получил ответ через выбранный VPN.
- «Нет ответа через VPN» — проверка не получила ответ; туннель остаётся включённым.

После успешного ответа новая проверка запускается через15s; при ошибке в ручном
режиме — через5s после завершения запроса. Проверка двух DNS-серверов может занять
до5s. Это не мгновенный индикатор и не проверка доступности всех приложений.
Проверки идут через VPN, не через резервный обычный интернет. DNS-запросы короткие,
но влияние фоновых проверок на батарею/Doze на физическом телефоне ещё не измерено.

Если звонок работает, а индикатор сообщает об отсутствии ответа, не требуется
немедленно отключать VPN: DNS может быть недоступен отдельно от голосового трафика.
В ручном режиме новая диагностика сама не перезапускает туннель и не меняет транспорт.
Auto сохраняет свою прежнюю политику; для текущего пилота оставляем Auto выключенным.

«Проверить внешний IP» теперь выполняет HTTPS через сеть текущего VPN и отвергает
результат после смены сеанса. При потере VPN проверка завершится ошибкой. Целевой
сервис — Cloudflare; ожидаемый адрес Амстердама186.246.45.246.

## Установка после приёмки

1. Отключить VPN и установить beta03 поверх beta02 тем же beta-сертификатом.
2. Сохранённый AWG профиль используется повторно: новый ключ/профиль не требуется.
3. Выбрать AmneziaWG3.1, Auto выключен, подключиться, дождаться результата связи.
4. Проверить внешнийIP, сайт, сообщения и звонок. Эти проверки можно выполнить позже
   на российском телефоне; эмулятор не заменяет проверку МТС/Ростелекома.

## Отложенные проверки телефона

- Заблокировать экран на5min, затем открыть сайт и сделать звонок.
- Переключить Wi-Fi→МТС→Wi-Fi с включённым AWG; записать время восстановления.
- Проверить пользовательское Disconnect при отсутствии сети: VPN должен остаться
  выключенным после возврата Wi-Fi/мобильной сети.
- Сравнить расход батареи при обычном использовании; не менять настройки MIUI
  энергосбережения заранее, чтобы сначала увидеть штатное поведение.

APK не удалять ради отката: это удалит локальные данные. Работающий beta02 остаётся
доступен как прежний артефакт; Android может запретить downgrade code3→code2.
Сервер и профиль не меняются при этом обновлении клиента.
