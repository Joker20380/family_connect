# Android beta01 — первый технический тест

В этом круге проверяем WireGuard через Амстердам. APK содержит и другие
экспериментальные режимы, но для этого профиля выберите **WireGuard**, Auto выключите.
AWG3.1 и доставка конфигураций через Reticulum в этот тест не входят.

## Что получить

- `FamilyConnect-Android-0.1.0-beta01.apk`, примерно181MiB; Android8.0 и новее.
- Личный `Amsterdam-Android-beta-01.conf` — только для одного первого устройства.
  Другим тестировщикам выдаются отдельные профили. APK общий, профиль общий не делать.

Это закрытая техническая debug-сборка, не релиз Google Play. Она подписана отдельным
локальным beta-ключом, который будет сохранён для следующих обновлений. В интерфейсе
версия пока0.1.0/code1; beta01 — имя данного неизменяемого комплекта.

## Установка и проверка, примерно10–15 минут

1. Установите APK, разрешив установку из выбранного источника, если Android запросит.
   Если уже установлена другая Family Connect и обновление отклонено из-за подписи,
   остановитесь и сообщите ошибку. Не удаляйте прежнее приложение до согласования
   сохранения доступа: его локальные данные будут удалены при uninstall.
2. Откройте приложение. Выберите WireGuard, выключите Auto, нажмите импорт профиля
   и выберите личный `.conf`. При подключении подтвердите системный запрос VPN.
3. Нажмите «Подключить», дождитесь завершения. Нажмите «Проверить внешний IP»:
   ожидаются `186.246.45.246` и `NL`. Эта проверка обращается к Cloudflare.
4. Откройте два обычных HTTPS-сайта в браузере. Проверьте их работу, а не только
   значок VPN. Затем нажмите «Отключить» и проверьте обычный интернет.
5. Повторите подключение/отключение ещё два раза. При активном VPN заблокируйте
   экран на5 минут, вернитесь и повторите проверку IP/сайта.
6. Отдельно проверьте Wi-Fi→мобильная сеть, если доступны обе сети. Запишите,
   восстановилась ли связь и сколько это заняло. Успех этого сценария пока не заявлен.
7. Закончите тест нажатием «Отключить». Закрытие окна само по себе не равно отключению VPN.

После успешного импорта удалите переносимую копию `.conf` из общедоступных загрузок
телефона; не отправляйте её в отчёт/групповой чат. В приложении профиль хранится
зашифрованным через Android Keystore. Доступ остаётся отзывным оператором сервера;
автоматический срок действия этого ручного WG-профиля не реализован.

## Короткий отчёт

Модель телефона / версия Android; Wi-Fi или мобильная сеть; установилось ли;
3 подключения и3 отключения; IP/страна; работают ли сайты; поведение после блокировки
экрана и смены сети; время восстановления; текст ошибки без профиля и секретных ключей.
Не нужен полный logcat или выгрузка содержимого приложения.

## Границы готовности

Исходный Android APK прошёл CI build/lint/unit и API35 x86_64 emulator с WG/AWG/TCP/
Auto lifecycle и control verifier. При переподписи DEX/resources/native libraries
сохранены побайтно; менялись данные подписи. Финальный beta-сертификат проверен.
Профиль Амстердама прошёл DNS/HTTPS/download/reconnect в Linux namespace.
Это не заменяет установку финального APK и сетевые проверки на реальном Android.
После первого телефона решаем, расширять ли закрытый круг. Для массовой беты нужны
отдельная недебажная сборка с растущим versionCode, обновления, простой onboarding,
подтверждённые sleep/handover/recovery и аппаратная/ABI матрица.
