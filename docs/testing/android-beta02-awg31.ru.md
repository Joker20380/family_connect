# Android beta02: AWG 3.1 через Амстердам

Закрытый технический пилот, Android8+ с ARM64. APK48,8MiB; версия0.1.1-beta02/code2,
тот же beta-сертификат, что у beta01. Физическое устройство и звонки WhatsApp этой
сборкой ещё не приняты. ЭмуляторAPI35 и серверный Linux-клиент прошли проверки.

1. Отключить действующий VPN. Установить `FamilyConnect-Android-0.1.1-beta02-arm64.apk`
   поверх beta01. Если обновление отклонено, сохранить текст ошибки; не удалять
   старое приложение и его данные автоматически.
2. Выключить **Auto**, выбрать **AmneziaWG 3.1**.
3. Импортировать **новый** `Amsterdam-AWG31-Android-beta02.conf`. Старый WG-профиль
   для этого транспорта не подходит. Новый приватный профиль предназначен одному
   телефону; не публиковать его и не запускать одновременно на другом устройстве.
4. Нажать «Подключить», подтвердить системное разрешение VPN при запросе.
5. Открыть `https://api.ipify.org`: ожидается **186.246.45.246**. Открыть ещё один
   HTTPS-сайт. Отправить сообщение WhatsApp, затем проверить звонок в обе стороны.
6. При сбое записать время, тип сети (Wi-Fi/мобильная), работает ли сайт/сообщение,
   на каком этапе зависает звонок и есть ли звук. Не отправлять профиль/ключи/logcat.
7. Проверить отключение и обычный интернет; затем повторное подключение.

Профиль использует отдельный AWG3.1 endpoint186.246.45.246:443/UDP, MTU1280,
Header Protection, content padding и random trailers. Это не HTTPS-ссылка и не
REALITY: UDP443 сам по себе не гарантирует прохождение блокировок. IPv6 направлен
в туннель и блокируется на пилотном сервере, IPv4 выходит через Амстердам.

Android manual parser принимает булевы поля `true/false`; закреплённый серверный
`awg` tool требует `on/off`. Выданный Android-профиль уже имеет нужный формат.
Параметры пользовательских таймеров3.1 и подписанная Reticulum-схема3.1 пока
не поддерживаются. Auto остаётся выключенным для однозначного теста этого профиля.

После импорта удалить лишнюю скачанную копию приватного .conf. Для возврата к WG
отключить AWG, выбрать WireGuard и прежний профиль. Понижение APK с code2 до code1
может быть запрещено Android; для возврата транспорта понижать APK не нужно.
