# Уведомления и имена в мессенджере

## Просмотр, редактирование и голосовые (beta49)

Администратор: **Мессенджер → Family Connect → ⋮ → Опубликованные объявления**.
Нажмите заголовок, исправьте текст, откройте предпросмотр и «Сохранить изменения».
Список включает архив; более ранние записи доступны постранично. Получатели и срок
объявления при правке не меняются. Конфликт редакций требует открыть актуальную запись.
В публичном диалоге правки помечаются «Изменено». Клиентам beta43/44 доступна только
исходная неизменяемая лента; для правок обеим сторонам нужна beta45.

В личном чате удерживайте своё текстовое сообщение, чтобы изменить его. Чужие сообщения
редактировать нельзя. Правки передаются с подписью автора и шифрованием; исходный ID
сохраняется в истории, управляющие сообщения не отображаются отдельными пузырями.

Удерживайте микрофон справа от отправки: запись начинается в строке ввода,
отпускание отправляет. Свайп вверх фиксирует запись — уберите палец и нажмите
стрелку для отправки или крестик для отмены. Свайп влево при удержании отменяет.
На лимите60с запись останавливается и ожидает отправки. После выдачи разрешения
микрофона удержите кнопку заново. Новое сообщение автоматически показывается в чате.
Opus, моно, целевой bitrate12кбит/с, до60секунд/128КиБ. Запись на Android10+; доступ
к микрофону запрашивается только по нажатию. Уход из приложения отменяет неотправленную
запись; временные файлы приватные и удаляются, отправленная запись хранится зашифрованно.


## Администратор в Android (beta43)

Подключённому телефону владельца назначена роль администратора. Она привязана
к существующей идентичности приложения и проверяется сервером при каждом запросе.
В мессенджере откройте **Family Connect → ⋮**: появится «Вы администратор»,
заголовок, текст и предпросмотр. Кнопка «Опубликовать для всех» находится только
на странице предпросмотра; объявление публичное, срок отображения 30 дней.
При неопределённом результате связи повторная отправка с этой же страницы
использует прежний ID и не создаёт второй экземпляр.

Оператор может назначать/отзывать устройства через `scripts.service_notices`
`grant-device --access-db PATH --device PUBLIC_ID --name NAME` / `revoke-device
--device PUBLIC_ID` с приватным `--registry PATH`. Активная регистрация Friends
обязательна. Обычный пользователь и отозванная роль не могут публиковать.
Право назначать других администраторов в мобильный интерфейс пока не добавлено.
Токенный CLI ниже остаётся доступным для операторских автоматизаций.


## Android

Beta49 установлена и опубликована в updater. Страница первой активации пока выдаёт
beta35; после активации обновите приложение до49.
Системные уведомления о личной переписке и событиях сервиса имеют разные каналы.
Нажатие открывает нужный диалог; личный текст не выводится на экран блокировки.
У уже показанного уведомления сохраняется отметка, прочтение фиксируется отдельно.
Старая история при первом обновлении не порождает повторную массовую рассылку.

Меню мессенджера → «Мессенджер Family Connect»: фоновое получение и переход к
системным настройкам уведомлений. Служба не требует включённого VPN, но требуется
доступ к узлу сообщений. Android может ограничивать приложение во сне; после
принудительной остановки системными настройками требуется открыть приложение.
Это собственная служба получения, не FCM. Регистрация мессенджера и лента событий
используют обычную сеть вне VPN; получение личных сообщений также привязано к
основной сети. При обновлении/перезагрузке предусмотрен запуск включённой службы. Проверка длительного сна/Doze и других
производителей остаётся отдельной приёмкой.

Меню диалога → «Переименовать чат». Имя локальное, хранится зашифрованно,
используется в списке, заголовке и уведомлениях. Пустое поле возвращает исходное
имя. Ключ и проверенный fingerprint собеседника не меняются.

## События Family Connect

Отдельный диалог «Family Connect · события»: обновления, обслуживание, смена
сервера и общая информация. Это публичные объявления сервиса, а не личная E2E
переписка. Сообщение не выполняет команд, не переключает VPN и не устанавливает
обновления. Лента загружается с фиксированного HTTPS-адреса с проверкой сертификата;
приложение не принимает адрес ленты из сообщения или контакта.

Публикуют владелец и назначенные администраторы. Владелец управляет доступом на
сервере через защищённую ОС; публикация доступна администраторам по HTTPS с
индивидуальным токеном. Делегировать права через publishing API нельзя.

На сервере `185.251.89.19`:

```sh
cd /opt/apps/family_connect/friends-access/app
python3 -m scripts.service_notices --registry ../notices.sqlite grant --name administrator-name --token-file ../administrator-name.token
python3 -m scripts.service_notices --registry ../notices.sqlite revoke --name administrator-name
```

Первый владелец: `Owner`, токен хранится только в приватном файле
`/opt/apps/family_connect/friends-access/notices-owner.token` (0600).
Токены не добавлять в Git, сообщения, скриншоты, аргументы команд или журналы.
Реестр хранит только SHA256 токенов; отзыв запрещает последующие публикации.
Уже опубликованные объявления сохраняются в истории.

Администратор готовит JSON-файл с полями `id` (новый UUID без дефисов), `kind`
(`update`, `maintenance`, `server_change`, `information`), `title`, `body`,
`platforms` (список `android`, `windows`, `linux`) и `days` (1–365).
Повторять запрос после сбоя нужно с тем же id и содержимым — второе объявление
не создаётся. Менять уже опубликованный id нельзя. Максимум200 активных объявлений.

В рабочем дереве проекта:

```sh
python3 -m scripts.publish_service_notice --request-file notice.json --token-file administrator.token
# Предыдущая команда только показывает подготовленное объявление.
python3 -m scripts.publish_service_notice --request-file notice.json --token-file administrator.token --send
```

Endpoint: `/friends/notices/publish`; выдача прав через него не реализована.
Публичная лента: `/downloads/family-connect-events-v1.json`, без персональных данных.
На Windows/Linux пока нет рабочего UI мессенджера: указание платформы в событии
само по себе не добавляет туда уведомления. Их интеграция остаётся отдельной задачей.

## Откат серверного дополнения

Резервная копия: `friends-access/backup-notices-20260923/manifest.json`.
По manifest восстановить прежний access-api.py и nginx.conf/nginx-final.conf,
проверить nginx -t, перезапустить только family-connect-friends-access и перечитать
конфигурацию family-connect-product-https. VPN-службы/ключи пользователей не менять.
Реестр/токены/историю не удалять. На телефоне исправления устанавливать поверх
существующего приложения, без удаления данных.
