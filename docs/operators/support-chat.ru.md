# Адресная переписка поддержки

Используйте существующий аккаунт оператора в локальной панели
`http://127.0.0.1:8765/`. В карточке production-устройства откройте
**«Сообщения · личная поддержка»**. Общий список ответов: `/messages/`.
Это не `/system-messages/`: там публикуются объявления для всей выбранной аудитории.

Адресат определяется подтверждённой связью device identity ↔ chat identity,
а не именем или IP. При отсутствующей, неоднозначной, отозванной или просроченной
связи отправка недоступна. beta123 не подтверждает новый протокол поддержки;
для этого этапа подготовлен отдельный beta125. Не переносите ключ телефона в панель.

Статусы: «в очереди» означает сохранение у отправителя; «принято mailbox» —
передачу на сервер; «сохранено клиентом» — подписанный ACK после сохранения Android.
Подтверждения прочтения нет. Ответы принимает постоянный серверный процесс,
браузер не обязан оставаться открытым. После неизвестного результата отправки
повторяйте ту же форму с прежним текстом и ID, не создавая новое сообщение.

## Физическая приёмка владельцем

Подписанный ARM64 beta125 /0.1.18-beta125 пока не опубликован и не установлен.
Он сохранён локально в
`state-client-build/support-live-20261111/FamilyConnect-Test-0.1.18-beta125.apk`.
Размер50,470,304 байта; SHA256
`f1c5bf578a5ca1e8e864a60fa9ab33249807e22c4552b5da984d126720e5740c`.
Публичные каталог, invitation-page и ссылки загрузки не изменялись.

Оставшееся действие — одна согласованная сессия с телефоном владельца:
проверить фактическую версию, установить125 поверх неё без очистки данных,
открыть чат для подтверждения binding, затем выполнить разрешённый адресный обмен
при выключенном пользовательском VPN. Предложенный, ещё не отправленный текст:
«Проверка служебной связи Family Connect. Ответьте, пожалуйста: „Получено“».
Перед отправкой сверить именно canonical binding выбранного телефона.
Без подтверждения этого текста/адресата live-проверку не выполнять.

Обычный Wi-Fi и синтетическая истёкшая подписка проверены в изоляции;
холодный запуск без кеша под белыми списками остаётся отдельным полевым сценарием.
Получение публичных объявлений в production требует отдельного согласования
точного текста и рассчитанной аудитории; выбор Android означает всю платформу.
