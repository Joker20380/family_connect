# Компоновка приложений Linux и Windows

10.09.2026. Исправления исходников, без замены установленного приложения пользователя.

Причина обрезания: Linux использовал фиксированный вертикальный `pack` без прокрутки,
жёсткую ширину переноса и две кнопки в строке независимо от ширины текста. Windows
использовал TableLayoutPanel без явных row styles и ограничений ширины для длинных
локализованных статусов. Масштаб и сообщения об ошибках увеличивали требуемое место.

Linux: адаптивная ширина текста, две кнопки перестраиваются в один столбец, компактнее
шапка, прокручиваемая область и отдельный постоянный footer языка. Tab прокручивает
к выбранному действию; колесо работает в области окна. Минимальная ширина учитывает
реальный шрифт и текст кнопок при HiDPI, чтобы не обрезать сами подписи. Темная тема
кнопок/выбора профиля согласована с основным окном, disabled-состояния читаемы. При
отсутствии профиля поле поясняет следующий шаг. Таймер корректно отменяется при закрытии.

Windows: явные AutoSize строки, ограничение ширины меток с переносом, прокрутка основного
содержимого и отдельный footer; стандартное окно 480×620 client pixels, минимальное
360×420 с DPI scaling. Включён PerMonitorV2, пересчёт при изменении размера/DPI,
компактнее заголовок и отступы. Диалог кода устройства также переведён на адаптивную
таблицу с многострочным кодом и постоянной кнопкой копирования. Основные действия и
модель активации не менялись.

Проверки Linux: `xvfb-run -a python3 clients/desktop/layout_check.py`, 18 сочетаний
RU/EN × 360×420, 480×620, 800×700 × масштаб 100/150/200%. Проверяется горизонтальная
геометрия, полная ширина кнопок и доступность нижнего действия по фокусу при длинной
ошибке. На высоком масштабе минимальная физическая ширина может превышать запрошенные
360 pixels — это учитывает увеличенный шрифт. Пример обычного окна с длинной ошибкой:

![Linux, окно 480×620, RU](images/linux-layout.png)

Windows: .NET 10 cross-build прошёл без warnings/errors. Добавлен `/layout-test` для
144 сочетаний языка, состояния, размера и Scale 1/1.5/2, без обращений к broker;
он включён в Windows CI. **Этот WinForms runtime-тест здесь не запускался**: Linux
не предоставляет Windows desktop runtime. Программный Scale-тест также не заменяет
ручную проверку на Windows с реальными мониторами 100/150/200% и переносом окна между
мониторами. Перед выпуском установщика эту проверку нужно выполнить, включая диалог кода.
