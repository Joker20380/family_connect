# Android WG / AmneziaWG 2

Состояние приёмки и точные артефакты: [отчёт](releases/2026-09-12-android-awg.ru.md).

В приложении выбрать WireGuard или AmneziaWG 2, импортировать соответствующий
конфигурационный файл, затем подключить и разрешить системный VPN-запрос.
Перед сменой протокола нужно отключить соединение. Во время запуска кнопка
«Отключить» отменяет подключение. Удаление профиля действует только на выбранный
протокол. Состояние «подключено» сейчас означает, что backend поднял интерфейс;
это ещё не результат проверки доступности Интернета.

WG использует прежние `profile.enc` и AndroidKeyStore alias
`family-connect-profile-v1`; AWG — `awg-profile.enc` и отдельный alias с `-awg`.
Файлы находятся в noBackupFilesDir, содержат AES-256-GCM ciphertext; backup
приложения отключён. Открытые конфигурации сохранять в Git/CI/логах запрещено.
Импорт AWG проверяет обязательные J/S/H и необязательные I-поля, диапазоны,
дубликаты, размер, числовой endpoint и полные IPv4/IPv6 AllowedIPs.
Подписанная продуктовая активация Android остаётся следующей отдельной задачей.

Для сборки нужен чистый checkout, Linux amd64, Go1.26.1, Java17, Gradle8.11.1,
Android SDK35 и NDK28.2.13676358. Сначала выполнить
`ANDROID_NDK_HOME=<NDK-directory> python3 pilot/android-awg/build.py`, затем
из `clients/android`: `gradle --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`.
Из корня `python3 pilot/android-awg/verify-apk.py` сверяет хеши четырёх AWG ABI
и наличие лицензий; второй Go runtime в APK запрещён.
WG и AWG используют один native backend, WG-профили не содержат AWG-полей. Generated output игнорируется Git и не должен быть
оставшимся от другой ревизии: сборщик откажется перезаписывать существующий каталог.

`.github/workflows/clients.yml` запускает API35 x86_64 эмулятор. Только при
`GITHUB_ACTIONS=true` `pilot/android-awg/run.py` поднимает два синтетических
UDP peer на runner и инструментальный тест. Peer использует TUN в памяти;
маршруты и VPN хоста не меняются. AndroidTest содержит исключительно фиксированные
синтетические ключи, не включается в основной APK. Тест выдаёт приложению VPN
разрешение на одноразовом эмуляторе, проверяет IPv4/IPv6 обмены, остановку,
отмену и отзыв разрешения. CI сохраняет XML, build/runtime/crash logs и хеши APK.
Не запускать этот инструментальный тест на пользовательском телефоне.

Debug APK не опубликован как обновление. Android0.1.0/versionCode1 пока сохраняются;
перед реальной установкой нужны отдельная подпись, увеличение версии и принятие
на устройстве. Пользователь отложил это действие. Сервер и существующие клиенты
этим шагом не обновляются. Откат исходников — checkpoint13fffe9 до Android AWG;
откат установленного APK не требуется, поскольку rollout не выполнялся.

TCP, Auto, bound-health, Android delivery/activation, сон/Doze и смена сетей пока
не приняты. Используется стандартный Go runtime без upstream CLOCK_BOOTTIME patch.
ELF alignment16KB не заменяет проверку на устройстве с размером страницы16KB.
