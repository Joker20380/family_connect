# Настройки второго ноутбука — 11.09.2026

Применены: масштаб встроенного 3840×2160 экрана 200%, текст 100%, Ubuntu 11,
Ubuntu Mono 15 для системного моноширинного текста, Yaru-dark и Ubuntu Bold 11.
GNOME Terminal: палитра Matrix из первого ноутбука, Ubuntu Mono 12, мигающий блок,
73 столбца × 40 строк (высота адаптирована под экран 2160 вместо 2400 пикселей).
Первый ноутбук использует Ptyxis; перенесено оформление в установленный GNOME Terminal.
Особенности Mutter новой версии (xwayland-native-scaling) не перенесены в старую GNOME.

Zsh: настройки первого ноутбука с путями текущего пользователя; Starship 1.22.1,
fzf 0.67.0, fd 10.3.0, ripgrep 15.1.0, автоподсказки, дополнения и подсветка.
Программы находятся в ~/.local/share/laptop-style, без sudo и системной установки.
Starship/fzf/fd/rg скопированы из установленной системы первого ноутбука и проверены
на втором. bat 0.24.0 и libgit2/libhttp-parser получены из репозитория Ubuntu 24.04,
распакованы в личную папку; локальная библиотека используется только wrapper batcat.
История команд, ключи и настройки авторизации не переносились.

Резервная копия: ~/.local/state/laptop-style-backups/20260911-150001.
Для восстановления прежних настроек:

    python3 ~/.local/state/laptop-style-backups/20260911-150001/restore.py

Открыть новый терминал после применения/отката. Для текущего терминала: exec zsh.
Проверка живого масштаба через Mutter показала 2.0; monitors.xml сохранён с идентичностью
экрана второго ноутбука. Сохранение после нового входа и визуальное удобство проверяет
пользователь; перезагрузка/завершение его сеанса автоматически не выполнялись.
