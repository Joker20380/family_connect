## Изменение

Вместо бинарного удаления светлых пограничных пикселей используется их перевод
в полупрозрачный тёмный контур: светлая матовая подложка заменяется alpha coverage.
Обрабатывается только нейтральный светлый край, соседствующий с исходной
прозрачностью; решения принимаются до изменения пикселей. Внутренние белые
детали остаются, геометрия полутонового края не удаляется целиком.

Размер GIF относительно текста уменьшен с1,4 до1,15: маленькие архивные GIF
меньше растягиваются. FILTER_BITMAP сглаживание, полная высота GifSpan,
анимация с lifecycle и foreground polling beta16 сохранены.
Исходные49 GIF/их хеши не меняются; обработка только при отображении.

Сборка beta18/code18 ARM64/Android8.0+ выполняется с прежним beta-v1 ключом.
Сохраняются unit-проверки soft alpha/сохранения внутреннего белого и native
GIF animation/line height/cursor/draft/send/viewport. 140 unit и2 native UI passed, lint0errors/16warnings. Установлена на Redmi Note9 Pro
поверх beta17, SHA256 сверена. APK36390988bytes, SHA256
`857529786dd5c1798fe0b36b3d19630a08ead0fb35d0ca4148ed406b454eba45`.
Native рендер просмотрен. Пользователь затем попросил убрать заголовок панели —
это включается в beta19. Beta18 не публиковалась, публичная версия пока beta16.
План установки — поверх beta17 без удаления данных. До пользовательской
оценки контура основная публичная ссылка остаётся на beta16.

## Rollback / оставшееся

Предыдущие APK неизменяемы. Возврат клиента — новой сборкой code>18, прежним
сертификатом, без удаления приложения/переписки. Если beta18 публикуется,
откат страницы — nginx.conf/nginx-final.conf/invite.html.before-beta18-download
в /opt/apps/family_connect/state-product-https/config, с учётом дальнейших изменений;
nginx -t и HUP только family-connect-product-https. Пул инвайтов и сервер
мессенджера не меняются. После визуальной приёмки остаются другие устройства,
крупный шрифт, offline/restart/дубли и продуктовое оформление GitHub.
