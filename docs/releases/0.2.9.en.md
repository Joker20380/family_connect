# Family Connect 0.2.9 — Linux pilot updates

The repository includes standalone TCP updater setup sources without requiring a Git checkout on the target device, and
signed TCP component installation through a root-owned broker. Authenticate the initial
setup before running it as administrator. Installation backs up existing files,
preserves profiles and never starts VPN automatically.

Standalone TCP continues monitoring failed health checks without automatic privileged
restarts, preventing repeated password prompts and offering manual reconnection.
A failed start that already stopped TCP no longer requests redundant shutdown.
WG/AWG chain recovery and authorization cancellation remain supported.

Linux transport features still require --awg-pilot plus the corresponding system
components and profiles. Native Windows/Android AWG/TCP integration remains pending;
this release does not add Linux TCP functionality to Windows.

Linux pilot functionality is demonstrated, but ordinary-load timeouts remain a known
limitation. Isolated TUN/SOCKS each passed60/60; this is not a stability guarantee.
Further network testing was deferred by the user. No server upgrade is required.

Integration validation:273 local tests, GTK recovery and all platform/TCP/AWG/phase0 CI
passed. Publication requires successful versioned Linux, Windows and Android CI.
The signed update catalog is published separately after downloading and checking the release artifacts.
Standalone setup initial distribution remains separate from the desktop installer.
