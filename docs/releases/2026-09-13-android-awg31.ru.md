## Изменения

Engine b5928efb6ca19f0153958460c3d141f04abc5c2e (v3.1.20260828) с ранее
проверенным pilot/awg31 startup S4 patch. Android wrapper остаётся5420011143f9dd42831cc95fcdb0d6ac9bde868f,
расширяется явным patch; module path JNI и fixture переведён на /v3.
Ручной AWG профиль принимает HeaderProtectionKey (ненулевой32-byte Base64),
ContentPaddingAddition0..256/range, RandomTrailers и DisableCookies true/false.
При HPK требуются S1..S4>=12 и H1..H4=1,2,3,4; trailers требуют равные S.
Старые AWG2 профили остаются валидными; WG отвергает AWG поля. Таймеры3.1 пока
не входят в поддерживаемый набор. Native signed control schema по-прежнему
отвергает3.1: её исторические vectors не ослабляются ради ручного пилота.
[Официальное описание параметров](https://docs.amnezia.org/documentation/amnezia-wg/).

VersionName0.1.1-beta02/code2; UI показывает AmneziaWG3.1. APK ещё не выдан.
Эмуляторные peers и Android fixtures теперь используют одинаковый тестовый HPK,
padding/trailers; ключ03*32 — только синтетический, не production.

## Проверки и незавершённое

Начальная локальная Gradle попытка не загрузила native services из старого кэша.
Повтор с новым изолированным кэшем собрал Java;29/30 JVM tests passed. Новый
roundtrip test упёрся в существующее требование точной строки ::/0 при том, что
wrapper сериализует expanded IPv6. Roundtrip проверяется напрямую wrapper parser;
production profile validation не ослаблялась. Финальный повтор выполняется.
Нативная4ABI сборка, Android emulator runtime, Amsterdam AWG deployment/smoke,
подпись beta-ключом и проверка на физическом телефоне ещё не завершены.

Rollback: beta01 APK и WG peer сохранены. Android source до7fceed9 остаётся
предыдущей принятой версией. Новые серверные изменения пока не применены.
