# Карта кода по модулям

24.09.2026, по запросу пользователя подготовить понятную новому программисту карту
всего проекта. Изучены каталоги, entry points, существующая архитектура, текущие
STATUS/PLAN и профильные тесты. Это навигация по модулям, не аудит каждого метода.

Созданы пять страниц в `docs/code-map`: общий индекс, backend, clients, messaging,
operations. Описаны обязанности, точки входа, зависимости, данные, тестовые группы,
порядок знакомства, карта задач «где менять» и ограничения готовности. Разграничены
Friends/Product/fleet, managed wire и app updates, chat relay и QUIC laboratory.
Приватные runtime данные не читались и в карту не включались.

Добавлены ссылки из docs/README, architecture, CONTRIBUTING, STATUS и PLAN.
CONTRIBUTING требует обновлять карту при изменении module responsibilities/trust
boundaries. Из architecture удалена устаревшая привязка desktop к0.2.9: актуальные
версии по-прежнему берутся из STATUS, а не дублируются в описании структуры.

Проверки: штатный check_public_docs --all проверил320 Markdown-файлов и1893 ссылки,
ошибок нет; git diff --check также прошёл. Внешняя доступность URL этим не проверяется.
Карта содержит Mermaid-схему логических связей; браузерный rendering в этой работе
не проверялся. Runtime-тесты не запускались: изменены только документы.
Код, серверы и версии Android0.1.18-beta50/code50, Linux0.2.10, Windows0.2.13 прежние.
