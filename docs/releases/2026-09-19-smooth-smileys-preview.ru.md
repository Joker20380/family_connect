# Пять гладких анимированных смайликов — макет, 2026-09-19

Пользователь отклонил бахрому beta19 и разрешил заново нарисованный набор в духе ICQ,
сначала несколько образцов для оценки. Созданы оригинальные SVG: улыбка, подмигивание,
смех, грусть, поцелуй. Моргание, лёгкое движение лиц, появление сердца у поцелуя.
Прозрачный фон, непрерывные векторные контуры, жёлтая заливка с мягким градиентом.

Проверки: 10 SVG разобраны XML-парсером, все ссылки на изображения существуют;
в анимированных вариантах присутствует animateTransform, в статических отсутствует.
Chromium headless отрисовал страницу 1120×850; рендер просмотрен: пять лиц,
размеры 24/32/48 и примеры сообщений на двух фонах без обрезания.
Это проверка браузерного макета, не Android runtime и не пользовательская приёмка.
Новые Android tests/lint не запускались: код клиента не менялся.

Версии: установленная APK остаётся 0.1.18-beta19/code19, публичная —
0.1.15-beta16/code16. Хеши и предыдущие проверки: [beta19](2026-09-19-android-beta19.ru.md).
APK не собиралась, сервер и публикация не изменялись. Rollout отсутствует;
rollback макета не требует действий на телефоне/сервере. Следующая APK должна иметь
code>19 и прежний ключ, без удаления приложения и истории.

Решение пользователя: новый стиль отклонён, текущие смайлики пока оставить.
Макет сохранён как эксперимент; расширение и Android-интеграция отложены.
Бахрома остаётся известным визуальным недостатком. В этой фиксации решения
изменена только документация; `git diff --check` пройден, Android tests не повторялись.
Не публиковать beta19 из оставленных staging-файлов на основании этого решения.
