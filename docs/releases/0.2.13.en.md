# Windows0.2.13 — independent updates

Windows0.2.12 and earlier only checked the shared0.2.9 catalog, so newer manual previews
were invisible. Windows0.2.13 uses the independent signed `updates/windows.json` catalog,
schema2, platform=windows and increasing sequence. Signature/expiry, rollback and artifact
hash checks remain enforced; the release signing key stays offline.

Install0.2.13 manually once over the previous version. Future Windows releases can then be
found and downloaded using Check for updates, independently of Linux. UAC still confirms installation.
The Linux/shared catalog and Android beta50 are unchanged.
