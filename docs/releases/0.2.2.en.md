# Family Connect 0.2.2

Desktop visual refresh: graphite background, indigo accents, clearer typography and
rounded Windows buttons with keyboard/focus support. A temporary dodecahedron icon
is included in the window, Windows executable/installer and Linux launcher.

Scrolling and responsive layouts remain supported. Linux packages retain the six-file
format accepted by the 0.2.1 updater; the icon is embedded in app.py. Profiles, keys
and network behavior are preserved. The server remains on 0.2.1.

Editable icon source: clients/assets/dodecahedron.svg. Icon design will be revisited.
