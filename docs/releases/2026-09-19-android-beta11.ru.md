# Friends Android 0.1.10-beta11 — главный экран и карта маршрута

2026-09-19. Package `com.familyconnect.app.friends`, versionCode11.
Локальная тестовая сборка; GitHub Release и update catalog не публиковались.

## Что изменилось

С главного убраны оранжевая SYS-строка и две большие кнопки. Версия находится
в настройках. Активация доступна там же либо при первом нажатии «Подключить».
«Чаты» переименованы в «Мессенджер». Капсула переключателя уменьшена до51×31dp,
зона нажатия сохраняет высоту52dp. Цвет и положение отражают реальное состояние.

Добавлена панель фактических показателей: тип активной сети Android, Wi-Fi RSSI
при наличии, заряд и полоса батареи, скорость входящего/исходящего трафика UID
приложения и график последних48 измерений. Интервал около1с, история собирается
только пока экран активен. Это трафик всего приложения, не замер скорости VPN
и не пропускная способность канала. До двух измерений показывается прочерк,
при отсутствии RSSI — «нет данных». Новых разрешений на геолокацию/телефонию нет.

«Маршрут» открывается в полноэкранном окне с собственной кнопкой возврата.
Карта поддерживает pinch zoom1–3×, перемещение, двойное нажатие для сброса
и нажатие на регионы RU/NL для просмотра информации. Нажатие на карту не меняет
сервер автоматически: выбор подключения остаётся в доступных системных списках.
Под картой — страна, транспорт, состояние туннеля, проверка сети и внешний IP.
Результат проверки IP отображается прямо в разделе маршрута.

На карте изображён логический путь «устройство → выбранный регион». Геопозиция
устройства условная, точки представляют регионы, а не координаты дата-центров.
Промежуточные интернет-узлы не измеряются и не выдумываются. Выключенное состояние
показывает выбранный путь; соединение и проверка — реальные состояния сервиса.
Движение маркера обозначает ожидание, не движение конкретного пакета.
При переподключении выбранная страна отделена от региона текущей сессии.
Начальные события невидимых списков игнорируются; перед открытием маршрута
восстанавливается сохранённый выбор страны и транспорта.

Подложка — офлайн-полигоны суши [Natural Earth, public domain](https://www.naturalearthdata.com/about/terms-of-use/).
Источник и преобразование записаны в `clients/android/app/src/main/assets/maps/NOTICE.txt`.
Интерпретация отсутствующего уровня сигнала основана на
[Android NetworkCapabilities](https://developer.android.com/reference/android/net/NetworkCapabilities#getSignalStrength()).
Карта не обращается к провайдеру тайлов и не отправляет геолокацию.

## Проверка и воспроизведение

В `clients/android`, с тем же локальным окружением и проверенными native ABI,
что использовались для beta10:

```sh
gradle --no-daemon :app:testFriendsUnitTest :app:lintFriends :app:assembleFriends
gradle --no-daemon -PfcTestBuildType=friends :app:assembleFriendsAndroidTest
```

Main и test APK подписываются одним локальным beta-v1 сертификатом. Секреты
подписания не передаются в CI или Git. Установка — `adb install -r` без очистки
данных. `DashboardLayoutRuntimeTest` выполняется только для Friends; обычный
CI default/debug не переключён на Friends.

```sh
adb shell am instrument -w -r -e timeout_msec 45000 \
  -e class com.familyconnect.app.DashboardLayoutRuntimeTest \
  com.familyconnect.app.friends.test/androidx.test.runner.AndroidJUnitRunner
```

UI-проверка охватывает главный экран без ScrollView, границы основных кнопок
и зоны48dp+, viewport320×512dp, два положения переключателя, настройки,
полноэкранную высоту маршрута, нажатие NL на карте и сохранение настроек
страны/транспорта после открытия разделов. Состояние VPN, инвайты
и пользовательские настройки не изменяются. Рендеры — настоящие Android Views
через Canvas, без отключения FLAG_SECURE. Pinch/pan требуют отдельной ручной
проверки жестов; автоматизированное нажатие региона принято.

## Rollout / возврат

Установка поверх beta10 тем же сертификатом, versionCode11. Beta10 не изменяется.
Локальные кандидаты beta11 сохранены в `state-client-build/android-pilots/beta11/candidate1/`
и `candidate2/`;
он не публиковался. Для возврата прежнего UI собрать его с новым code>11,
тем же сертификатом, проверить и установить поверх. Не удалять приложение ради
понижения версии: это уничтожит локальные ключи. Сетевые службы и серверы
на этом этапе не менялись; инвайты не выпускались и не расходовалиcь тестом UI.

## Осталось

Ручная приёмка pinch/pan, TalkBack, больших системных шрифтов, landscape и Android15
insets; физическая VPN-матрица RU/NL × AWG/TCP, активация и два телефона для
мессенджера/QR. UI-проверка не заменяет эти сетевые gates. Продуктовое оформление
публичного GitHub остаётся обязательным этапом после messenger/device acceptance.
