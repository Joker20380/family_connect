Пользователь сообщил: активировал устройство по ссылке, число 500 не изменилось.
Read-only SQLite-запрос на разрешённом API-хосте 185.251.89.19 показал:
referral_claims=0, активированных referral claims=0, остаток=500.
Коды, ссылки и данные устройств не выводились. Новых приглашений не создавали.

Это подтверждает отсутствие расхода реферального пула, но не определяет, какой
ссылкой воспользовался пользователь. Прямые 50 приглашений — отдельный бюджет.
При referral/claim место расходуется при выдаче кода, не при активации.
В ReferralActivity число в подсказке «Общий пул: 500» является фиксированным лимитом;
строка remaining получает серверный остаток только при первоначальной загрузке.
Автоматического обновления открытого экрана нет.

Android остаётся 0.1.18-beta19/code19; desktop v0.2.9. Код, APK и сервер не менялись,
rollback не требуется. Проверка: read-only агрегаты и анализ UI/API исходников;
тесты runtime не запускались, поскольку изменений реализации нет.
Далее: при необходимости уточнить вид использованного приглашения; в будущем
различать в UI общий лимит и остаток, обновлять остаток при возврате на экран.
Desktop-этап остаётся основным. Не считать это доказательством сбоя активации.
