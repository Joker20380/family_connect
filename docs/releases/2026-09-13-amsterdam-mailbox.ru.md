## Компактность — обязательный принцип разработки

Сохраняем бинарный LXMF/MessagePack и шифрование Reticulum. Не добавляем JSON,
Base64, повторные публичные ключи или новые поля в каждое сообщение без измеренной
необходимости. JSON/hex в диагностических файлах и локальном encrypted Store
не означает такое же представление в сетевом сообщении. Канал конфигураций отделён.

Измерение одной реальной отправки короткого текста:

| Уровень | Размер |
| --- | ---: |
| UTF-8 текст `ping` | 4 байта |
| Подписанный LXMF | 115 байт |
| Зашифрованный envelope в spool | 208 байт |
| RNS interface TX за publish | 855 байт |
| RNS interface RX за publish | 416 байт |

Дельты интерфейса включают поиск/установление связи, identify и служебный обмен;
они не включают все TCP/IP заголовки и не являются размером одного envelope.
Текущий Mailbox открывает новый link на операцию для ограниченного жизненного
цикла. Фоновый announce узла раз в60с также требует трафика; idle-трафик отдельно
ещё не измерен. Размеры не объявляются минимумом протокола.

Следующая задача: воспроизводимый бюджет байтов для короткого текста, серии
сообщений, пустого fetch и idle; затем измеренное сокращение служебных обменов
(повторное использование link с пределом простоя, объединение запросов при
сохранении commit-before-purge, announce по необходимости). Сначала сравнить
трафик/задержку/восстановление, затем менять поведение. Подписи, доверие к identity,
защиту от повторов и долговечность хранения ради нескольких байт не ослаблять.

## Изоляция и нагрузка

Служба family-connect-mailbox, отдельный пользователь fc-mailbox, root-owned
code/venv/settings и постоянная приватная node.identity. Всё runtime-состояние и
TMPDIR на отдельном ext4 image64MiB; spool по-прежнему262144 байта/128 сообщений,
SQLite максимум786432 байта. MemoryMax192MiB, TasksMax64, CPUQuota25%, запись только
в state. Проверяются отдельное устройство/mount и root-owned marker; случайный
bind mount обычного каталога не проходит preflight.

После теста MemoryCurrent24420352 байта (~23.3MiB), MemoryPeak24850432 (~23.7MiB),
NRestarts0. Том занят233472 байт, доступно57102336. На сервере доступно676MiB RAM.
Это малая нагрузка двух тестовых клиентов, не тест ёмкости или защиты от DoS.
Увеличение VPS для этого пилота не требуется; предел одновременных клиентов не измерен.
