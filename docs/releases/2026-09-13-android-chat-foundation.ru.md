# Android: ключ истории и классические смайлики — 13 сентября 2026

Следующий ограниченный шаг Android-интеграции: ChatKeyVault и ChatKeyEnvelope.
Отдельный alias family-connect-chat-store-v1 в AndroidKeyStore шифрует случайный
32-байтовый ключ Python Store. Файл61 байт в getNoBackupFilesDir, AES-256-GCM с
отдельным AAD family-connect/chat-store-key/v1, случайным nonce и AtomicFile.
ProfileStore/VPN-ключи не менялись. create — только явное первое создание;
load при отсутствии alias, неправильном ключе или повреждении отказывает.
Потеря файла при сохранившемся alias также не вызывает автоматическую генерацию.
Неудачная первая запись оставляет alias для явного восстановления, без скрытого reset.
Владелец должен стирать возвращённый byte[] после закрытия Store. Один процесс
приложения владеет vault; это не межпроцессный lock или механизм резервного копирования.

## Смайлики: требование пользователя

Нужны именно классические жёлтые **анимированные** смайлики ICQ2000-х. Рисованный
нами вариант удалён до commit. Найден архив49 GIF/374251 байт в MyHoldFast/icq_client,
commit165549533e629ed3e7890e23391a20284663981a. Восемь исходных GIF встроены в
[страницу для визуальной сверки](../design/icq-classic-preview.html), без изменения
пикселей/кадров и без удалённых загрузок. Хеши в icq-classic-reference.json.
Архив — кандидат: точная официальная версия/происхождение и разрешение на
распространение в приложении пока не установлены. В Android assets GIF не включены.
Не выдаём найденную стороннюю коллекцию за подтверждённый официальный дистрибутив.

Источники: [архив GIF](https://github.com/MyHoldFast/icq_client/tree/165549533e629ed3e7890e23391a20284663981a/smiles),
[статичные адаптации оригиналов ICQ Lite в Licq](https://github.com/licq-im/licq/tree/f271d550228d0b1ad07791cece43d5bcc2afa251/qt-gui/share/emoticons),
[отдельный набор ICQ Kolobok 2008 года](https://www.adiumxtras.com/index.php?a=xtras&xtra_id=6074).
Эти наборы не смешиваются автоматически. Пользователь уточнил эпоху2000-х;
визуальное совпадение конкретного архива ещё не подтверждено.

ChatSmileys — начальная таблица восьми текстовых обозначений, поиск только между
пробелами/границами строки, сохранение UTF-16 offsets и неизвестных кодов.
Оригинальный текст подписывается и передаётся без изменения. Код2–3 UTF-8 байта
не содержит GIF/Base64; локальный клиент позже отрисует соответствующий ресурс.
Сейчас нет Android image renderer, picker или анимационного lifecycle. Восьмёрка —
образец, не ограничение будущего полного набора. Unicode emoji остаются обычным текстом.

## Проверки и границы

JDK17 (gradle:8.11.1-jdk17), SDK35 android.jar: javac успешно компилирует
ChatKeyVault/ChatKeyEnvelope/ChatSmileys. JVM-проверки: AES roundtrip, разные nonce,
61 позиция изменения ciphertext/nonce/version, неправильный ключ, неверные длины;
восемь кодов, кириллица/суррогатная пара, границы URL и текстовый fallback.
Команда clients/android/chat-tests/check.sh с ANDROID_JAR и CHAT_CHECK_OUTPUT.
Контейнер --network none, исходники/SDK readonly; никакого assemble/package.

Это **не** runtime-проверка AndroidKeyStore/AtomicFile на устройстве. Instrumentation,
падение во время записи, переустановка/потеря alias, доступность ключа после сна
ещё требуют проверки. Python/RNS ещё не встроен в Android: JNI/embedded runtime,
передача ключа в Store и OS connectivity/foreground callbacks не реализованы.
Keystore hardware backing не предполагается и не заявляется.
