## Очистка, версии и откат

Существующая systemd TCP-служба временно запускалась с независимым stop timer150s.
Gateway bypass и public TUN route проверены. После finally stop полные IPv4/IPv6 rules
совпали с baseline; TUN и active marker отсутствуют, guard timer остановлен.
VPN оставлен выключенным, как до теста. Бинарники, MTU, offloads, timeouts и сервер
не менялись; откат установки не требуется.

Stable Linux0.2.7, desktop release0.2.8, TCP0.1.0 и server0.2.1 остаются прежними.
GitHub API подтверждает публикации tcp-v0.1.0/v0.2.8 и успешные последние CI:
phase0 на84ab8ec/6e3a2e2, Client builds/TCP/phase0 на92308a4.
Для локального HEAD1623719 и пяти незакоммиченных клиентских файлов новый CI не запускался.
Эти пять файлов сохранены без изменения. Нового deployment/release не выполняли.

Исходные scripts/JSON: ignored state-client-build/session-2026-09-11-first;
рабочая копия /tmp/fc-first-resume. Они содержат локальные сетевые metadata, не публиковать
их целиком как общедоступные логи. Продуктовый код не менялся, unit suite не повторяли.
