# Friends 0.1.14-beta15 — понятный мессенджер и ICQ-смайлики

2026-09-19. Пользователь подтвердил обмен сообщениями между телефонами на beta14,
после чего запросил привычный интерфейс мессенджера и ранее подготовленные смайлики.
Это подтверждение обычного обмена, не отдельная проверка offline/restart/дублей.

## Изменения

Вместо инженерной страницы с множеством кнопок — список диалогов с последним
сообщением и сортировкой по времени. Переписка открывается отдельно: входящие
сообщения слева, исходящие справа, время/статус доставки возле сообщения.
Постоянный composer: кнопка смайликов, поле ввода, отправка. Нижние вкладки остаются.
Карточка с ключом, регистрация, проверка отпечатка и ручное обновление — в меню.
Без подтверждения доставки не показывается выдуманное прочтение/online собеседника.
Контакты пока обозначаются короткими идентификаторами; полноценные имена/аватары,
поиск, непрочитанные и другие функции Telegram этим этапом не заявляются.

При обновлении истории не пересоздаётся поле ввода, сохраняются текст/курсор
и положение прокрутки, если пользователь читает выше. Черновики при переходе
между диалогами сохраняются в RAM и при повороте; после смерти процесса не сохраняются.
Во время записи отправляемого сообщения новый набранный текст не стирается.

49 исходных GIF ICQ уже были в assets, но старый ChatActivity использовал TextView.
Теперь встроен ChatSmileyTextView и выбор смайлика рядом с вводом. GIF локальные,
всего374251bytes; в хранилище/подпись/доставку по-прежнему идёт исходный текст
с кодами смайликов, без изменения протокола. Обычные Unicode emoji тоже остаются
обычным текстом. Анимация учитывает foreground, видимость и общую настройку движения.

Новая настройка мессенджера пытается зарегистрировать доступ сразу после создания
локального состояния; при ошибке сохраняются локальные ключи/история и доступен
явный повтор. Существующая регистрация при открытии сохраняется.

## Rollout / rollback и оставшееся

Установка поверх beta14 с сохранением данных; новый versionCode15.
Beta14/13 и прежние URL сохраняются неизменными. После UI-проверки beta15
опубликована: nginx -t passed, HUP только HTTPS-контейнеру. Полное публичное
скачивание проверено по SHA256, HTML /invite/ совпал с исходником.
[Скачать beta15 ARM64 —36,4МБ](https://185.251.89.19:8443/downloads/FamilyConnect-Test-0.1.14-beta15.apk).
Обновление на другом телефоне — открыть новую APK и выбрать «Обновить»,
не удаляя приложение и без нового приглашения. Автообновления нет.
Резервные конфигурации в /opt/apps/family_connect/state-product-https/config:
nginx.conf.before-beta15-download, nginx-final.conf.before-beta15-download,
invite.html.before-beta15-download. Для отката ссылки восстановить эти файлы
с учётом последующих изменений, выполнить nginx -t и HUP. Возврат интерфейса — новой сборкой с code>15 и тем же ключом,
без удаления приложения/истории. Серверы мессенджера и пул приглашений не меняются.

Остаются пользовательская оценка нового интерфейса и реальная переписка со
смайликами; offline/restart/дубли, другие устройства/крупный шрифт/клавиатуры.
Затем запланированное продуктовое оформление GitHub.
