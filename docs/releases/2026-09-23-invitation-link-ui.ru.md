# Активация по ссылке и единое окно — 2026-09-23

## Требования

Доступ **только по приглашению**, последнее подтверждение пользователя 23 сентября.
Установка сама по себе не выдаёт доступ. Личный ключ устройства сохраняется;
копирование и ручной ввод кода исключаются из нового интерфейса. За образец принят
Android: тёмно-зелёный экран, шапка family_connect, круг подключения, выбор страны
и протокола на главной, карта, постоянная нижняя навигация.

## Подготовленные изменения, ещё не публичный выпуск

Страница приглашения передаёт исходный referral token по
`familyconnect://invite/<64 hex>` после нажатия «Открыть приложение».
Пользователь сначала устанавливает приложение и возвращается к исходной ссылке.
Cookies и выбранный приложением браузер не участвуют. Для встроенного браузера
Telegram на странице есть подсказка открыть ссылку во внешнем браузере.

Клиент сохраняет идентичность до сетевого запроса, делает существующий
`/friends/referral/claim` с устойчивым request_id устройства, затем подписанную
активацию `/friends/activate`. Код не показывается пользователю. Повторная попытка
использует тот же claim/ключ. Уже активированное устройство подтверждает доступ
без повторного приглашения. Отзыв остаётся на сервере. Открытый `/friends/register`
не добавлен: без приглашения новая идентичность отклоняется.

Лимиты существующего Referrals: 20 новых claims за скользящие 24 часа на
приглашающее устройство; 500 claims суммарно для кампании. Пересылка ссылки
сама по себе лимит не расходует. Это лимиты устройств/claims, не учёт людей.

Windows: служба проверяется по SCM/PID и конфигурации LocalSystem вместо
недоступного обычному пользователю OpenProcess. Экран доступа встроен в основное
окно; повторная ссылка передаётся существующему экземпляру. Установщик требует
UAC для службы и регистрирует URL protocol; обычный запуск приложения — без UAC.

Linux: встроенные доступ/QR/подтверждения, обработчик ссылки через Gio.Application.
Парный пакет содержит scripts/install_control_desktop.py для установки проверенного
bundle и desktop MIME handler. Существующий шестифайловый архив остаётся совместимым;
полная активация Friends требует парного Python core и его зависимостей.

Android: страна/протокол на главной; маршрут и настройки заменяют содержимое того же
Activity вместо Dialog. Ссылка обрабатывается singleTask Activity. Приглашение
обменивается в приложении, личность остаётся прежней после обновления.

## Rollout / rollback

Новый сценарий **не опубликован**. Публичные загрузки остаются Android beta35,
Linux bundle146d221d0ad23c07, Windows a6c68fe/0.2.9. Сервер и БД не менялись.
Не выкладывать новую страницу с существующими старыми установщиками: они не имеют
нового обработчика приглашения. Сначала завершить нативные проверки клиентов,
выпустить неизменяемые артефакты, проверить их подписи/хеши, затем согласованно
обновить ссылки страницы и её CSP hash. Нового серверного endpoint не требуется.

До rollout сохранить старые страницу/nginx CSP и каталоги обновлений. Откат:
возврат прежних загрузок/страницы; идентичности и БД не заменять. При обновлении
не удалять данные приложения. Физический Windows-компьютер в Петербурге недоступен.
