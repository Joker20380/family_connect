## Остаток и доступ

Реальные записи ещё не внесены. Внешней резервной копии нет. Следующий шаг — согласовать
поэтапный перенос нужных записей без нарушения работающих служб, затем создать копию
на отдельном носителе и проверить её открытие. Не удалять исходные рабочие ключи до
проверки восстановления. Ноутбук онлайн не становится физически офлайн signing station.

Открывать базу через KeePassXC, пароль вводить локально. После работы блокировать базу
(Ctrl+L) и экран ноутбука. Потерянный мастер-пароль нельзя восстановить из файла базы.
Откат изменений Git не удаляет локальную базу. Удаление хранилища не выполнялось и
не требуется для отката source guard; оно уничтожило бы единственную текущую копию.
