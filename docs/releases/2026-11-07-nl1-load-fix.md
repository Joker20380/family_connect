readback is retained. TCP identity/email/flow must match one actual account; malformed
or duplicate snapshots fail closed. Lookup is linear, not a per-device full-list scan.
No persistent runtime cache, longer polling interval or stale snapshot reuse is added.

The existing120s lease,2s tick, wall/monotonic/boot fences, canonical membership,
