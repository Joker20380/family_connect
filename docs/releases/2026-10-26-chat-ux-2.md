## Exact Android contract

The [catalog](../../clients/desktop/smiley_catalog.json) records all49 entries in
Android106 order: canonical tokens, every alias, RU labels, filenames and SHA256.
It also pins the Java parser/renderer/picker/contour sources and provenance record.
Build-time parity parses `ChatSmileys.java`; missing/renamed/modified/extra GIFs
fail packaging. The package contains exact Android GIF bytes in its own read-only
asset directory, never a checkout path, downloaded pack or user-writable pack.

Matching uses Java `Character.isWhitespace` semantics (including NBSP exclusions),
longest matching alias, and at most8 successfully decoded images per message.
Unknown/missing/corrupt images remain literal text. Pango shapes reserve inline
image space in a selectable label whose text and clipboard remain the original
tokens. The Android exterior-matte contour calculation is applied only to decoded
display frames; bundled GIF bytes are unchanged.

The49-item scrollable popover inserts canonical tokens with minimal boundary
spaces, replaces selection, enforces4096 UTF-8 bytes atomically, restores focus,
supports arrow/Tab/Escape navigation and never sends on selection. Unicode emoji
and mixed Cyrillic/combining text remain ordinary unnormalized text.
One page-owned animation clock updates mapped, viewport-visible labels only while
the chat page and window are active. Hidden/offscreen labels pause; unmap/recycling
unregisters them; full close removes the clock and window watcher. Sidebar previews
remain plain text. No message text/positions are logged by the renderer.
