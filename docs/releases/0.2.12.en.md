# Windows0.2.12 manual preview

The reported symptom in0.2.11 was white flashing when changing country or transport.
Selectors now draw a single buffered frame, without first drawing the native Windows field.
Dark layout containers are buffered, state changes are applied together and the hidden
activation button no longer appears transiently. Unchanged telemetry avoids extra repainting.

Native regression changes country/transport eight times and checks that the header is not
invalidated and hidden controls do not toggle. UI/startup/DPI, installer/broker/URI,
ordinary-user and AWG/TCP checks passed. Physical smoothness on the reported PC remains pending.
