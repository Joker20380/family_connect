Family Connect 0.2.1 is a pilot maintenance release for Linux and Windows.

- Responsive desktop layout, wrapping statuses, scrollable content and accessible buttons at compact sizes.
- Signed, opt-in update checks in both desktop apps. Reticulum catalog delivery remains planned.
- Visible application version; existing profiles and device keys are preserved when updating.
- Windows installer includes the existing native VPN service and official WireGuard driver. The installer itself is not Authenticode-signed; this is a pilot release.
- Product server adds authenticated provisioning, durable cache/version handling and gateway peer reconciliation. Native applications still use their existing activation/profile flows.

Windows: run the new installer over the existing installation. Updating restarts Family Connect services and may briefly interrupt its VPN connection. Do not uninstall or delete the key store first.
Linux: extract the archive and run install-linux.sh as your normal user, then reopen the application. NetworkManager profiles are preserved.

SHA256SUMS and release.json describe these exact files. The catalog is informational and unsigned, not an authorization source for unattended updates. The app uses the separately signed updates/pilot.json catalog; unattended installation remains planned.
