# Family Connect 0.2.2

Обновлён внешний вид Linux и Windows: графитовый фон, сиреневый акцент, ясная
типографика, зелёный статус включённого туннеля. Временный значок — додекаэдр.
Значок включён в окно, Windows EXE/установщик и Linux launcher.

Кнопки Windows скруглены с сохранением клавиатуры и focus-индикации. Linux
сохраняет прокрутку и адаптивную компоновку. Архив совместим с обновлятором 0.2.1.
Профили, ключи и сетевое поведение не меняются. Серверная версия остаётся 0.2.1.

Editable icon: clients/assets/dodecahedron.svg. Platform assets: PNG/ICO;
Linux embeds its image to preserve the six-file archive accepted by 0.2.1.

Validation and publication: see [STATUS](../STATUS.md).
