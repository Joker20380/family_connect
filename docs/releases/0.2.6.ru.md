# Family Connect 0.2.6

Linux: узкое окно, по одной кнопке в строке, высота строго по содержимому.
Без дополнительного запаса высоты; прокрутка нужна только на небольшом экране.

Linux opens narrower with all action buttons in a single column, even when the window
is widened. Window height follows the content and footer, without a scaled minimum
height or spare vertical area. Scrolling remains available if content exceeds the screen.
Height updates are coalesced and unchanged content does not request window geometry.

Real laptop verification: 658×1078; content 993 pixels + footer 85 pixels; all actions
visible and one-column ordering confirmed. 24 layout/scale cases and polling regressions
passed. Release and installation evidence: [STATUS](../STATUS.md).

Windows functionality, VPN profiles/keys and server configuration are unchanged.
