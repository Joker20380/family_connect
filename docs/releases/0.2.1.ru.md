# Family Connect 0.2.1

Добавлена проверка подписанных обновлений по кнопке. Доставка уведомлений через Reticulum пока планируется.

Пилотный выпуск Linux и Windows: адаптивная компоновка, перенос длинных статусов,
прокрутка, доступные кнопки и видимый номер версии. Профили и ключи при обновлении сохраняются.

Windows: запустить новый установщик поверх существующей установки. Он перезапустит
службы Family Connect; возможно краткое прерывание его VPN. Предварительно удалять
приложение и хранилище ключей не нужно. Установщик пока без Authenticode-подписи издателя;
официальная подпись драйвера WireGuard сохраняется.

Linux: распаковать архив, выполнить install-linux.sh обычным пользователем и повторно
открыть приложение. Профили NetworkManager сохраняются.

Серверный этап добавляет product API, версии provisioning и согласование peers.
Приложения пока используют существующую активацию/импорт профилей.
SHA256SUMS и release.json описывают файлы выпуска. Каталог updates/pilot.json подписан
отдельным ключом Ed25519; установка требует подтверждения пользователя. Политика дальнейших обновлений: [updates](../updates.ru.md).
