# Friends 0.1.16-beta17 — чистый контур и полная высота ICQ GIF

2026-09-19. После принятой пользователем анимации/входящих beta16 получены два
замечания: белая кайма на тёмном фоне и обрезание верхней части смайликов в тексте.

## Исправления отображения

В исходных архивных GIF обнаружены нейтральные светлые пиксели внешнего контура.
Исходные49 GIF не меняются. ChatGifContour при отображении кадра удаляет только
светлые нейтральные пиксели, непосредственно соседствующие с исходной прозрачностью
или внешней границей. Все решения сначала записываются в отдельную маску;
удаление не распространяется внутрь белых областей. Проверены сохранение
окружённых глаз/зубов, жёлтого цвета и отсутствие последовательной эрозии.
Это ограниченная обработка внешнего контура, не глобальная замена белого цвета.

Movie рисует очередной кадр в небольшой переиспользуемый Bitmap. При изменении
кадра применяется маска, масштабирование выполняется с FILTER_BITMAP_FLAG.
Размеры кадров ограничены существующим проверенным набором (до64×64), массивы
и Canvas выделяются при создании GIF, не в каждом проходе анимации.

GifSpan явно резервирует полную высоту изображения и небольшой запас в font
metrics. Рисование идёт от baseline-height без повторного вычитания descent,
которое могло выносить верх изображения за выделенную строку. Text selection,
сохранение исходных текстовых кодов и доставка остаются прежними.

## Rollout / rollback

Установка поверх beta16 без удаления данных. Предыдущие APK/URL сохраняются.
После native проверки — отдельный URL beta17 и основная кнопка /invite/.
Откат страницы: nginx.conf/nginx-final.conf/invite.html.before-beta17-download
в /opt/apps/family_connect/state-product-https/config, с проверкой последующих
изменений; nginx -t и HUP только family-connect-product-https.
Возврат APK — code>17 и прежний ключ, без удаления переписки.
Сервер доставки, протоколы, пул инвайтов и исходные GIF не меняются.
Пользовательская оценка краёв/обрезания остаётся после установки; другие
устройства, крупный шрифт, offline/restart и полная VPN-матрица — отдельные проверки.
