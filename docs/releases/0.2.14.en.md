# Windows 0.2.14 — installer compatibility

Repairs installation left incomplete when the previous apphost could not start.
Service preparation uses Windows PowerShell and SCM, preserving encrypted data.
The application host opts out of CET for compatibility with older Windows 10
servicing levels; this removes hardware shadow-stack protection for this app's
processes, without changing system mitigation settings. Other protections remain.
Setup requires Windows 10 1809 or later, x64. Runtime is bundled. Failures now
include process exit code and, when managed code runs, the installation stage.
Native CI and publication are pending. Windows 10 physical-PC acceptance is pending;
Windows Server runner checks are not evidence of a Windows 10/11 device test.
