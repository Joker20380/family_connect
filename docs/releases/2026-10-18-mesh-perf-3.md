## COUNTER_SEMANTICS_AND_INSTRUMENTATION

Verified in **accepted**, not main, `reliablestream/engine.go` and `stream.go`:

- Writable is `next-base < min(local SendWindow, remote ReceiveWindow)` after
  negotiation. Default local send8/receive16/payload16384/RTO1s/max32 is unchanged.
- A SACK sets `pending.sacked`; it neither removes the block nor releases its
  position. Cumulative ACK deletes earlier entries and advances base.
- Receive SACK can include the head. Cumulative ACK advances after the ordered
  output handoff/`consume`; this does **not** identify which Android consumer is
  slow, nor prove that all downstream application processing is complete.
- `BufferedBytes` includes sender pending **and** receiver reorder storage.
  `SendDepth` counts retained blocks; neither is a physical-flight byte count.
- `SendContext` request completion is the async writer's endpoint `SendContext`
  result. For Telemost this is local carrier queue acceptance, not remote ACK or
  actual RTP delivery. The unchanged async engine can process ACKs while writing.
- Mux credit is debited on DATA queueing and replenished by WINDOW_UPDATE.
  Existing `FlowStalls` also includes unopened/queue waits; it is not credit-only
  blocked duration. The new counters separate those meanings.

Histograms retain count, sum and maximum, not invented exact percentiles. Event
rings may overwrite; counters survive. Durations must be differenced between
snapshots of the **same** session. Sampling a multi-layer snapshot is not an atomic
cross-layer transaction. Stale ticker timestamps cannot move the accounting clock
backwards or count elapsed time twice. Close/reset freezes clocks and retains
cumulative counters while clearing live storage.

No per-packet file I/O or additional per-packet allocation count. One-time bounded
recorder/engine storage and snapshot allocations are explicit. No payload, TLS
plaintext, room descriptors, tokens, identity keys or certificates are logged.

### Remaining observation limits

Exact bytes residing in Pion/SFU/the physical path are still not observable.
Telemost queue **frames** and accepted bytes are not a coherent physical-flight
gauge. Enqueued-retained bytes are a local boundary classification, not queue
occupancy. First-ACK lifetime includes local delivery/ACK return and sometimes
consume; it is not pure RTT. Retransmitted samples remain recovery lifetimes.
Receiver-component attribution needs receiver evidence; stock Android was not
instrumented. TLS write entry lengths do not independently prove the ciphertext
record layout. Retired per-stream records can miss a final handoff that finishes
after retirement; aggregate successful handoff totals remain available.
