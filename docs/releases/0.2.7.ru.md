# Family Connect 0.2.7 — нативный Linux-интерфейс

Linux-клиент переведён с Tk на GTK 4/libadwaita. Компактная шапка, скруглённая
карточка подключения, нативные список подключений, диалог подтверждения и выбор файла.
Сохранены одна колонка кнопок и высота окна по содержимому. Начальный список профилей
и состояние VPN применяются вместе. Неизменившееся состояние не обновляет свойства
элементов. Профили, ключи, NetworkManager и механизм проверки обновлений сохранены.
Windows остаётся отдельным нативным приложением; серверное поведение не менялось.

## Требования Linux

Python GI, GTK >=4.8, libadwaita >=1.2, cryptography и NetworkManager.
Ubuntu/Debian: `sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 python3-cryptography`.
На ноутбуке пользователя зависимости уже были установлены; системные пакеты не менялись.
Архив из шести файлов совместим с прежним механизмом обновления. На другом Linux
зависимости нужно установить заранее: неудачная проверка запуска сохраняет старую
установку. Обновлятор не устанавливает системные пакеты автоматически.

## Проверки

27 Python-тестов; 24 варианта GTK-разметки при масштабе 100–250%; проверки целостности
начального состояния, выбора профиля, неизменившихся и устаревших ответов, независимости
действий от медленного опроса и отмены подтверждения. Проверена совместимость с GTK 4.8
и libadwaita 1.2.

На ноутбуке: GTK 4.22, libadwaita 1.9, нативный Wayland; окно 390×548 логических пикселей.
За восемь секунд — два начальных обновления состояния, без периодических изменений
свойств элементов. После двух секунд прогрева максимальный интервал контрольного
таймера и p95 — 16,2 мс при заданных 16 мс; процессорное время 0,154 секунды.
В предыдущем замере Tk был разрыв 1,4 секунды вне Python-обработчиков. Это короткий
замер на конкретном ноутбуке, а не гарантия одинаковой производительности на всех
системах. Оценка внешнего вида и плавности пользователем ещё предстоит.

[Модель отрисовки GTK](https://docs.gtk.org/gtk4/drawing-model.html).

и [phase0](https://github.com/Joker20380/family_connect/actions/runs/34519567996) прошли успешно.
Файлы опубликованного выпуска скачаны, SHA256SUMS проверены до подписи каталога
с порядковым номером 6. Linux обновлён механизмом версии 0.2.6; проверка запуска
прошла, предыдущая версия 0.2.6 сохранена. Значок и идентификатор приложения обновлены.
Для нового интерфейса нужно переоткрыть приложение.

Установщик Windows 0.2.7 опубликован; установка на личном ПК не подтверждена.
Сервер остаётся на 0.2.1. Текущее состояние: [STATUS](../STATUS.md), дальнейшие шаги:
[PLAN](../PLAN.md).
