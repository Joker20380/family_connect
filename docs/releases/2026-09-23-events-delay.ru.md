# Задержка объявления — Android beta44, 2026-09-23

Пользователь отправил объявление; на втором Android beta43 диалог оставался пустым,
затем сообщение появилось. Серверная проверка показала одно сохранённое объявление
через73 секунды после публикации. Причина задержки: клиент обновлял ленту раз в300с,
открытие диалога и завершение отправки читали только локальную копию.

Исправлено: общий интервал фоновой/foreground проверки30с, немедленная загрузка
при открытии Family Connect и после публикации. Открытый диалог обновляется при
изменении ленты независимо от циклов обмена личными сообщениями. Открытый мессенджер
получает объявления и при выключенной фоновой службе. Ошибка обновления показывает
сохранённые сообщения и понятный статус. Сетевой статус личного чата больше не
перезаписывает статус формы администратора. Это polling, не push: Android/OEM/Doze
по-прежнему могут задерживать фоновые запросы.
