## Откат и оставшиеся действия

RU: `systemctl disable --now family-connect-peer-worker.service`, дождаться stop,
затем `systemctl enable --now family-connect-peers.timer` и проверить успешный цикл.
Оригинальные unit/timer остались на месте. Никакого restore БД или restart VPN.
NL: `systemctl disable --now fail2ban` снимает управляемые им bans; не очищать
firewall целиком. Конфиг/пакет можно оставить для повторного включения.

Открыто: длинное наблюдение после прогрева защиты, остаточные bursts/await NL,
проверка предоставленных VPS IOPS/latency условий при воспроизводимой проблеме,
контроль автоматического TLS renewal. Не менять SSH password policy без отдельного
решения оператора и проверки альтернативного доступа. Для дальнейшей диагностики
использовать iostat-/proc sampling и bounded чтение **только текущего** journal,
не исторические широкие scans. Новый supervisor runbook содержит recovery ограничения.
