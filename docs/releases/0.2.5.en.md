# Family Connect 0.2.5

Linux opens with a font-aware window size so controls are visible at startup on HiDPI
screens, including systems whose actual font metrics disagree with Tk scaling.
Rounded connection selector, custom chevron, styled dropdown and application-themed
update/close confirmation dialogs replace inconsistent toolkit defaults.

Background VPN status reads use a separate executor and a 3-second timeout; slow
NetworkManager responses no longer queue user actions behind polling. Layout requests
are coalesced, unchanged layouts/scroll regions are skipped, pending callbacks cancelled
on close, and unchanged launcher files are no longer rewritten/fsynced on every launch.

Verification: 24 layouts (100–250%), startup visibility, slow-poll/action independence,
existing polling regression. Real laptop: effective font scale 2.06, window 988×1028,
all main actions visible; themed confirmation cancelled successfully. No live VPN action
was performed during the UI check. Windows functionality and server remain unchanged.

Release/installation state: [STATUS](../STATUS.md).
