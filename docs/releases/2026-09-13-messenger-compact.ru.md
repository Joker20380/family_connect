# Компактная отправка очереди — 13 сентября 2026

Добавлен Mailbox.publish_many:1–4 различных message ID передаются через один
аутентифицированный RNS link. Общий deadline по умолчанию12с, максимум30с, без
фонового соединения/таймера. Link закрывается в finally при успехе, ошибке и отмене.
Предел4 соответствует исходному burst узла; использованные ранее токены могут
вызвать rate_limited. Автоматического обхода ограничения/повтора нет.

Каждый ciphertext передаётся прежним бинарным put и получает отдельный FULL-commit
ACK. Подтверждённое сообщение сразу relayed; при отказе последующие не отправляются.
Неподтверждённый начатый элемент возвращается queued; повтор использует прежний
ciphertext, защита от дубликатов сохраняется. Уже relayed не означает прочтение или
прикладное подтверждение сохранения у получателя. Одиночный publish использует тот
же механизм для одного элемента. Receive и commit-before-purge не изменены.
