# Windows0.2.11 manual preview

Windows0.2.11 fixes the reported initial size, resized layout and stale header painting.
The header, dial and navigation now use consistent DPI dimensions; content stays centred
in a wide window. Selectors, buttons and invitation inputs use the application palette.
The installer and shortcuts use the current door logo.

A device key is created locally on first launch. Server access still requires an invitation:
open the original full invitation link or paste it into **Activate with invitation**.
Installation by itself does not grant access. Existing identity and access survive updates.
