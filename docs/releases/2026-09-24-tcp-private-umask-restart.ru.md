# Применение TCP UMask0077 —24.09.2026

Пользователь разрешил перезапуск. Перезапущены только
`family-connect-friends-tcp.service` последовательно: сначала NL, после проверки
его порта — RU. Перезагрузка хостов и перезапуск AWG/API не выполнялись.
TCP-сессии на перезапускаемом узле могли прерваться; число затронутых пользователей
и время их автоматического восстановления не измерялись.

## Предварительные проверки

Оба узла: TCP/AWG active, настроенный UMask0077, TCP User=fc-friends,
server.json regular root0640. Проверка `xray run -test -config` выполнена от
fc-friends с exit0, весь приватный вывод подавлен. Это проверка доступа и формата,
без публикации содержимого конфигураций, Environment, ключей или записей клиентов.

## Результат

На каждом узле restart exit0; локальный listener восстановился, через5 секунд
MainPID ненулевой и новый, ActiveState=active, NRestarts=0. В `/proc/<MainPID>/status`
Umask=0077: подтверждена настройка именно работающего процесса, а не только unit.
Файл конфигурации остался0640. AWG MainPID сохранён и ActiveState=active.

С ноутбука установлены TCP-соединения к NL443 и RU8446. NL проверен до начала RU
restart, после него повторно проверены оба публичных порта. Это не проверка
авторизованного VLESS/REALITY handshake, маршрутов/DNS или полезного трафика клиента.
Длительный soak также не выполнялся.

Отложенный пункт TCP runtime umask из предыдущего аудита закрыт. Настройки drop-in
остаются в системе для следующих запусков. Новые key/config values не создавались,
права существующих секретов и версии бинарников не менялись.

## Продолжение и откат

Далее остаются актуальная зашифрованная резервная копия серверного состояния,
проверка восстановления, внешний носитель и устранение ненужных plaintext копий
после перевода потребителей. Этот перезапуск не закрывает весь план секретов.

При несовместимости нового creation policy откатить только `70-private-files.conf`,
выполнить daemon-reload и отдельный согласованный restart затронутой TCP-службы;
содержимое server.json не менять. Откат не понадобился. Публичные версии приложений,
каталоги обновлений и пользовательские ключи прежние. Документируется операция,
не новый выпуск приложения.
