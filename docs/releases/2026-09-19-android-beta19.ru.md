# Friends 0.1.18-beta19 — смайлики без заголовка и мягкий контур

2026-09-19. Финал визуальной итерации после замечаний пользователя к краям beta17.
[Beta18](2026-09-19-android-beta18.ru.md) добавила мягкую прозрачность контура и
уменьшила масштаб GIF1,4→1,15 от размера текста; затем пользователь попросил
убрать надпись «Смайлики ICQ». В beta19 заголовок панели выбора удалён полностью,
доступная подпись кнопки — «Смайлики»/Smileys. Авторство/лицензии assets сохранены.

Исходные49 GIF не перерисовываются. Нейтральный светлый внешний matte при
отображении переводится в alpha coverage, не удаляется бинарно; окружённые
внутренние белые детали сохраняются. Полная высота GifSpan и анимация сохранены.
Входящие без ответа (foreground polling6сек) и движение пользователь уже
подтвердил на beta16. Beta17/18 не публиковались; их APK сохранены.

Beta19/code19 установлена поверх beta18, SHA256 сверена.140 unit и2 native UI
passed, lint0errors/16warnings; APK36390988bytes. SHA256
`5ebe38168f084d3e19bb740722ec7c3a7ceb5e9ed63508efc3e3ff3f5e0bf3a4`.
Пользователь отклонил контур: «край всё ещё грязный». Заголовок панели убран,
но визуальная задача не принята. Beta19 не опубликована. Подготовленные
beta19-upload.apk/beta19-invite-upload.html/publish-beta19.py на сервере
не включены в публичную конфигурацию. Основная ссылка остаётся beta16.
Запрошено решение: новый гладкий анимированный набор в стиле ICQ либо сохранение
строго оригинальных GIF; до ответа перерисовка не начинается.
Сборка: `gradle --no-daemon :app:testFriendsUnitTest :app:lintFriends :app:assembleFriends -PfcTestBuildType=friends -PfcTargetAbi=arm64-v8a :app:assembleFriendsAndroidTest`.
Native проверки включают смену кадров, pause/resume, полную высоту GIF,
сохранение ввода/курсора, передачу исходных кодов и размер viewport.

## Выпуск / rollback

Установка поверх beta18 без удаления приложения, данных или активации.
После визуальной оценки — отдельный URL beta19 и обновление /invite/.
Предыдущие опубликованные APK/URL неизменны. Откат страницы —
nginx.conf/nginx-final.conf/invite.html.before-beta19-download в
/opt/apps/family_connect/state-product-https/config (сравнить с последующими
изменениями), nginx -t и HUP только family-connect-product-https.
Возврат клиента — новой сборкой code>19 с прежним ключом, без удаления истории.
Остаются оценка краёв на телефоне, другие устройства/крупный шрифт,
offline/restart/дубли и продуктовое оформление GitHub.
