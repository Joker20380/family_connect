## Происхождение и точность

Пользователь запросил именно классические жёлтые анимированные смайлики ICQ2000-х.
Найденный сторонний архив сохранён без перерисовки/перекодирования; SHA256 каждого
файла записан. Точная официальная версия ICQ, происхождение всех49 файлов и
разрешение на распространение в релизе остаются неустановленными. Продолжение работы
не считаем отдельным подтверждением идентичности архива историческому набору.
Это архивный кандидат для прототипа, не подтверждённый официальный ресурс ICQ.
[Источник](https://github.com/MyHoldFast/icq_client/tree/165549533e629ed3e7890e23391a20284663981a/smiles).
Проверить происхождение/условия до публичного распространения. Новых APK нет.

## Передача и отображение

69 текстовых обозначений для49 смайликов. Короткие2–3-байтовые коды и длинные
традиционные команды до11 ASCII байт, например *THUMBS UP*. Добавлены привычные
:D и :P как алиасы исходных :-D и :-P. Код не является исполняемой командой:
это только локальное отображение обычного подписанного текста.
Картинки, Base64 или новый manifest по Reticulum не отправляются. Исходная строка
не меняется при создании ImageSpan; неизвестный код/отсутствующий ресурс сохраняется
текстом. Сопоставление только между whitespace/границами строки, чтобы не менять
URL/части слов. Внутренние пробелы в *IN LOVE* поддержаны; longest-match по алиасам.

Компонент minSdk26 использует Android Movie, читает только встроенный именованный
asset (имена из фиксированной таблицы), не URLs/вложения/пользовательские файлы.
Чтение ограничено32768 байт на GIF, размеры64×64. Реальные файлы максимум28109 байт,
максимальные ширина51 и высота34. Не более8 анимированных вхождений на один TextView;
остальные остаются текстом. Это ограничение одного сообщения, не всего экрана.

Анимация по умолчанию выключена. Владелец экрана вызывает
setForegroundActive(true/false); additionally проверяются attached, focus, window
visibility, isShown и пересечение видимой области. Один callback на TextView,
перерисовка с шагом40мс только при видимости. Скрытие/потеря focus/detach/rebind
снимают callback; выход за viewport останавливает его при следующем callback.
На входе в viewport следующий draw возобновляет его. Скрытое время не перематывает
анимацию; большие паузы кадра ограничены100мс. GIF не изменены, но точная частота
исходных кадров на реальном устройстве и минимальные/нулевые задержки требуют
визуальной проверки. Это не доказательство конкретного расхода батареи.

setMessage(original) привязывает текст; clearMessage освобождает ссылки на Movie
при recycle. Методы вызываются UI thread. Store/transport получают исходный текст,
не View. Content description сохраняет текстовые коды. Picker, экран чата и
accessibility-озвучивание названий эмоций ещё не интегрированы.
