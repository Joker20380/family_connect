# Friends Android 0.1.9-beta10 — компактный терминальный интерфейс

Дата: 2026-09-19. Package `com.familyconnect.app.friends`, versionCode10.
Это локальная тестовая сборка, а не публикация GitHub Release.

## Изменения

Главный экран Friends больше не содержит ScrollView. Высоту свободной области
занимает круговой индикатор; кнопки маршрута, приглашения и четыре раздела снизу
остаются на экране. Страна, транспорт и проверка IP доступны через «Маршрут»;
управление анимацией — через «Настройки». Вспомогательные диалоги могут прокручиваться.

Добавлены оранжевые акценты, тонкие рамки, собственные линейные значки и капсульные
переключатели. Выключенное состояние оранжевое, включённое зелёное; положение
переключателя VPN следует реальному сервису. Доступность сети отдельно отображается
текстом и кольцом. Анимация ожидания не выдаётся за процент выполнения.
Плавный переход переключателя180мс; сектор ожидания2,6с; есть отключение анимации.
Повторный render не задаёт неизменившийся текст заново каждые500мс.

[Источники Silo, сопоставление с изображениями пользователя и ограничения](../design/android-terminal.ru.md).
Сетевое ядро, протоколы, приглашения и серверы в этом этапе не изменялись.

## Воспроизведение проверки

В `clients/android`, с настроенными JDK17, Python3.10, SDK35, Gradle8.11.1 и
предварительно проверенными четырьмя native ABI:

```sh
gradle --no-daemon :app:testFriendsUnitTest :app:lintFriends :app:assembleFriends
gradle --no-daemon -PfcTestBuildType=friends :app:assembleFriendsAndroidTest
```

Ручной параметр `fcTestBuildType` выбирает Friends target для UI-приёмки;
по умолчанию остаётся debug. DashboardLayoutRuntimeTest пропускается в других
вариантах, где FriendsActivity не является launcher. Workflows для этого этапа
не менялись. Подписать main/test APK одним локальным beta-v1 сертификатом,
проверить payload/zipalign/signature, установить через `adb install -r`.
Ключи и пароль не передаются в CI и не записываются в публичный отчёт.

```sh
adb shell am instrument -w -r -e timeout_msec 45000 \
  -e class com.familyconnect.app.DashboardLayoutRuntimeTest \
  com.familyconnect.app.friends.test/androidx.test.runner.AndroidJUnitRunner
```

Первый запуск через ActivityScenario зависал в `Instrumentation.startActivitySync`
на MIUI. Тест теперь открывает Activity стандартной shell-командой `am start`
и ограниченно ожидает RESUMED в инструментируемом процессе. Разрешение
INJECT_EVENTS не менялось; пользователь оставил телефон разблокированным.

Тест измеряет настоящий View tree, проверяет отсутствие ScrollView, границы
основных кнопок и высоту зон нажатия не меньше48dp. Затем сохраняет native Canvas
рендеры основной области, viewport320×512dp, двух положений переключателя и
открытого диалога настроек. Эти рендеры не отключают FLAG_SECURE и не изображают
фиктивно активированную учётную запись. Синтетические два переключателя рисуются
отдельно, без изменения VPN/настроек пользователя.

## Rollout и возврат

Установка — поверх существующего Friends APK с тем же сертификатом и сохранением
данных. Внутренние кандидаты beta10 сохранены отдельно в `candidate1/`, `candidate2/`;
ни один не публиковался в GitHub или update catalog. Beta09 и её hash не изменены.

При необходимости вернуть прежний экран: собрать исходники UI из контрольного
состояния beta09 с новым versionCode больше10, подписать тем же beta-v1 ключом,
проверить и установить поверх. Прямой downgrade non-debuggable APK может быть
отклонён Android; не удалять приложение и не очищать его данные ради отката.
Схема локального хранилища и серверные данные этим UI-этапом не менялись.

## Оставшиеся проверки

Ручная активация, физическая VPN-матрица RU/NL × AWG/TCP, обмен сообщениями через
реальный UI двух телефонов и сканирование QR камерой ещё не приняты.
Шесть успешных изолированных chat runtime проверок относятся к предыдущему
этапу beta09; здесь они заново не запускались. Требуется отдельная приёмка
ландшафтной ориентации, Android15 edge-to-edge и увеличенных системных шрифтов.
Публичный download/update release ещё не опубликован. После messenger/device
приёмки остаётся согласованный этап продуктового оформления GitHub.
