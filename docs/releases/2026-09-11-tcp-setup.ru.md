из шести публичных файлов source 84ab8ec в `~/family-connect-test/client-84ab8ec`;

Два предупреждения из прежнего пользовательского GTK settings.ini: gtk-modules и
gtk-application-prefer-dark-theme; запуск не блокируют, визуальная приёмка ещё нужна.
Это тестовая копия исходников, не новый опубликованный desktop release.
Bootstrap сохраняет backup/restore.json в `/var/backups/family-connect/tcp-updater-*`;
компонент использует `/var/backups/family-connect/tcp-bundle-*`. Для отката bootstrap использовать сохранённый `restore.json` из указанного backup;
TCP установлен; для его отката использовать tcp-bundle-yog98jxv/restore.json.
VPN не запускался. Для удаления тестового GUI достаточно убрать указанные тестовую
папку и отдельный pilot desktop entry; стабильного клиента на втором ноутбуке не было.

с проверкой очистки; интеграция исходников, CI, доверенная публикация bootstrap и новый
клиентский выпуск. Не копировать личные профили первого ноутбука автоматически.
