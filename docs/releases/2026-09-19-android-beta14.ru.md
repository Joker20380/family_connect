# Friends 0.1.13-beta14 — компактная ARM64 APK

2026-09-19. Package `com.familyconnect.app.friends`, versionCode14.
Пользователь попросил уменьшить файл для раздачи друзьям. Также подтвердил, что
достаточно QR и ссылки со скачиванием; автоматическая передача кода в приложение
не нужна для текущего этапа.

## Размер и совместимость

APK `FamilyConnect-Test-0.1.13-beta14.apk`: 36382796 bytes (36,4 МБ),
вместо 240501071 bytes (240,5 МБ) у универсальной beta13 — примерно на85% меньше.
Android8.0+, только ARM64 (arm64-v8a). Beta13 с четырьмя ABI остаётся доступной
отдельно для остальных устройств. APK с одинаковой версией/именем не заменяются.

Причины размера beta13 по ZIP:185МБ четыре libfc-awg.so;33МБ остальные native
библиотеки, включая Python/криптографию;16,6МБ assets/chaquopy. Интерфейс/карта
не являются основной причиной. В beta14 упаковывается только ARM64 и включено
сжатие native libraries (useLegacyPackaging): Android извлекает их при установке.
Это уменьшает скачивание, но не на столько же установленный объём приложения.
Все9 ARM64 .so побайтово совпадают с beta13; сетевой/криптографический код не менялся.

Gradle property `-PfcTargetAbi=arm64-v8a` явно включает компактный вариант;
по умолчанию остаются прежние четыре ABI и прежняя упаковка. Неподдерживаемое
значение отвергается. Проверка APK принимает `--abis arm64-v8a` только явно,
сверяет точный набор фактически упакованных ABI и SHA256 по исходному манифесту.
По умолчанию проверка требует четыре ABI: beta13 passes, compact beta14 rejects.
