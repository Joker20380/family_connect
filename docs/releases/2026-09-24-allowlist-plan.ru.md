обновления конфигураций, сетевой приёмки и будущего управления в Django7.1.
[Полные требования, источник и ограничения](../allowlist-connectivity.ru.md).

Приоритет текущего5.3а сохранён. Его локальный обзор продолжается; код в этой
итерации не менялся, тесты Android на телефоне не запускались по ранее указанному
пожеланию пользователя. Протокол Shuka не установлен, рабочая схема для проекта
ещё не выбрана. Новый режим не объявлен реализованным или проверенным.

в документе требований и ссылается на действующую карту кода. Production, runtime,
серверы и публичные артефакты не менялись. Версии Android beta50/code50, Linux0.2.10,
Windows0.2.13 прежние. Откат этого изменения затрагивает только документы.
Проверки: ссылки документации, git diff --check и public source guard; тесты кода
не требуются для изменения плана. Следующий локальный шаг —5.3а; обследование5.3в.1
не требует запуска тестов на личном телефоне.
