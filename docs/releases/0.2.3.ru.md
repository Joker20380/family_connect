# Family Connect 0.2.3

Слегка скруглены кнопки; додекаэдр повёрнут вокруг трёх осей, без фронтальной грани.
Убрано дёрганье при проверке подключения: фоновый опрос не включает «Выполняется…»,
не блокирует кнопки и не перерисовывает неизменившееся состояние. Запоздалые ответы
не перезаписывают пользовательские действия. Ошибки опроса и восстановление видны.

Профили, ключи и серверная конфигурация сохраняются. Обновление доступно по кнопке.
Значок воспроизводится командой `python scripts/generate_app_icon.py` (нужен Pillow).

Проверки: Linux — 18 компоновок и регрессия фонового опроса; Windows — сборка без
ошибок/предупреждений. Платформенный CI и публикация: см. [STATUS](../STATUS.md).
