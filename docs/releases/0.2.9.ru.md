# Family Connect 0.2.9 — обновление Linux-пилота

В репозиторий добавлены исходники самостоятельного TCP updater setup, не требующего Git checkout на целевом устройстве, и
проверку подписанного TCP-компонента через root-owned broker. Первичный setup должен
быть получен из доверенного канала до запуска администратором. Установка сохраняет
профили, делает резервную копию и не включает VPN автоматически.

Одиночный TCP больше не перезапускается автоматически при failed health checks:
мониторинг продолжается, приложение предлагает ручное переподключение. Это прекращает
повторные запросы пароля. Лишний запрос на остановку уже неактивного TCP после failed
start устранён. WG/AWG recovery и отмена системной авторизации сохранены.

Транспортные функции Linux по-прежнему включаются через --awg-pilot и требуют
соответствующих системных компонентов/профилей. Windows/Android native AWG/TCP пока
не реализованы. Windows в этом выпуске не получает Linux TCP-возможности.

Функциональность Linux-пилота проверена, но при обычной нагрузке ранее наблюдались
тайм-ауты. Изолированно TUN/SOCKS60/60 на путь прошли; это не гарантия устойчивости.
Дальнейшие сетевые испытания отложены пользователем. Серверные изменения не требуются.

Проверки исходной интеграции:273 local tests, GTK recovery и все platform/TCP/AWG/phase0
CI passed. Публикация требует успешного CI Linux, Windows и Android для новой версии.
Подписанный каталог появится отдельно после скачивания и проверки релизных артефактов.
Первичная доверенная поставка standalone setup остаётся отдельной от desktop-установщика.

Опубликован source42f9d32; exact clients/TCP/phase0 CI прошёл. Артефакты скачаны/проверены; офлайн-каталог sequence8 проверен. Устройства не обновлялись.
