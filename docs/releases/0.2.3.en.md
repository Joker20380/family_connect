# Family Connect 0.2.3

Slightly rounded buttons and a dodecahedron rotated around all three axes, with no
front-facing face. Background connection polling no longer flashes Working, disables
buttons or redraws unchanged status. Late poll responses cannot overwrite user actions.
Polling failures and recovery remain visible.

Profiles, keys and server configuration are preserved. Install using Check for updates.
Regenerate the icon with `python scripts/generate_app_icon.py` (requires Pillow).
Linux: 18 layout cases and polling regressions passed. Windows cross-build passed
without warnings/errors. Platform CI and rollout evidence: [STATUS](../STATUS.md).
