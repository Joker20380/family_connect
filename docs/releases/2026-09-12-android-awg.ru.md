# Android WG/AWG — 2026-09-12

Статус: реализация подготовлена, сборка и приёмка CI ещё не завершены.
Этап 4: Android после принятого Windows Auto `1e13c74`.

Добавлены выбор WG/AmneziaWG 2, отдельный зашифрованный AWG-профиль,
строгая проверка параметров AWG, отмена запуска и обработка отзыва VPN.
WG сохраняет прежние файл и AndroidKeyStore alias; AWG имеет отдельные.
Удаление AWG не удаляет WG. Одновременно используется один VPN, переключение
требует остановки. Ошибка очистки сохраняет состояние с повторной остановкой.

Исходники: [официальный Android backend](https://github.com/amnezia-vpn/amneziawg-android/tree/5420011143f9dd42831cc95fcdb0d6ac9bde868f),
[движок](https://github.com/amnezia-vpn/amneziawg-go/tree/1cc94272ca8e9e223a5fe76382f5880f09d3c12d).
Go 1.26.1, NDK 28.2.13676358; arm64-v8a, armeabi-v7a, x86, x86_64.
AWG имеет отдельное имя libfc-awg.so, WG сохраняет libwg-go.so.
Сборщик исключает root backend, публичный UAPI, сигнальный дамп стеков,
отключает журналирование движка, синхронизирует JNI handles и закрывает
устройство при ошибке конфигурации. Проверяется результат protect UDP-сокетов.
В APK включены лицензии и manifest с ревизиями и SHA256 каждой AWG библиотеки.
Побитовая воспроизводимость разных сборок не заявлена.

Проверки: запланированы 12 JUnit методов, lint, проверка APK/четырёх ABI,
изолированный API35 x86_64 эмулятор с настоящим VpnService и шифрованным
UDP к Linux peer с TUN в памяти. Профили/ключи только синтетические;
пользовательские данные, сервер и устройства не используются.
Сценарии: WG→AWG→WG→AWG, по три IPv4 и IPv6 обмена за подключение,
очистка после остановки, отмена запуска, отзыв VPN-разрешения, независимые профили.
Эмулятор: [официальный runner](https://github.com/ReactiveCircus/android-emulator-runner).

Android versionCode 1 / versionName 0.1.0 сохранены. Debug APK является CI-артефактом,
не выпуском для установки. Desktop 0.2.9 / catalog seq8, установленный Linux0.2.7,
последний отчёт Windows0.2.7, сервер0.2.1 и TCP Setup0.1.0 не менялись.
Rollout не выполнен; откат установленного приложения не нужен.
Для возврата исходников использовать предыдущий checkpoint13fffe9;
не устанавливать этот debug APK поверх пользовательского приложения автоматически.

Остаются Android TCP и Auto, подписанная доставка/активация, принятие на устройстве,
внешний gateway, HTTPS/DNS, сон/Doze, смена Wi-Fi/mobile и восстановление.
Использован стандартный Go runtime без upstream CLOCK_BOOTTIME patch;
долгая работа/сон не приняты. Проверка на устройстве с 16KB page size не выполнена.
После интеграции Android — этап5 Reticulum. Пользователь отложил установку APK
и реальные/нагрузочные тесты; они не возобновляются этим шагом.
