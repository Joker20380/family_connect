  активный AWG блокирует обновление. `awg-quick` адаптируется для pinned userspace

  исходный bundle до этих двух проверяемых преобразований скрипта.
- Каталог использует true/false; Linux tools требует on/off. Helper преобразует
  только проверенные поля при записи и обратно при чтении, включая cleanup.
- Friends apply использует общий owner, durable journal, health и rollback.
  GUI Linux/Windows предлагает TCP REALITY и AWG 3.1.
- Windows Friends имеет отдельный runtime объект, без поддельной legacy подписи.
  Полный IPv4 из /16 проходит через network, health и journal v2; старый v1 читается.
  Native Windows пока явно требует DNS `1.1.1.1`/MTU `1280`; будущие несовместимые
  подписанные параметры отклоняются, а не игнорируются.

## Rollout и rollback

Новых публикаций, установки desktop/APK, изменения серверов или подписания не было.
GitHub releases по read-only API: desktop `v0.2.9` (2026-09-11), TCP `tcp-v0.1.0`,
`tcp-setup-v0.1.0`; Android по последнему checkpoint `0.1.18-beta19/code19`.
Шесть файлов standalone Linux archive сохраняются; Friends требует paired core.

Для Linux собрать reviewed checkout через `pilot/awg31/Dockerfile`, извлечь
`/opt/awg31/` в закрытый рабочий каталог, после отключения VPN применить
`sudo sh clients/linux/install-awg.sh SOURCE_CHECKOUT BINARY_DIRECTORY`.
Не применять новый installer к старому AWG2 bundle. Установка на пользовательский
хост в этом этапе не выполнялась. Windows требует полного нового installer.

Публикация: отдельная immutable версия после platform CI/render/interaction,
скачивания и проверки assets; затем `scripts/sign_update.py` с local release key и
возрастающим sequence. Не заменять `v0.2.9` и не передавать signing key в CI/server.

Откат: остановить VPN и завершить cleanup новым helper/broker прежде чем вернуть
проверенные прежние бинарники. Старый broker не читает pending journal v2, старые
Linux tools не читают31. Identity/cache не удалять; profiles/keys не коммитить.
Server rollout отсутствует. Открыты live Friends на обеих платформах, проверка из РФ,
новый signed выпуск, desktop messenger/QR/карта; анимация отложена.
